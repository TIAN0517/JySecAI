# Core Playbooks — 高價值攻擊劇本（含真實案例對照與紅線）
# Source: src-hunter-skill playbook 結構， adapted for JySecAI
# 每條 playbook：觸發場景 → 步驟 → 紅線 → 案例對照

## PB-01 IDOR 水平越權（案例基數 465）
觸發：URL/請求體出現連續 ID（/api/orders/10023、?user_id=1024）
步驟：
1. 註冊雙帳號 A/B，各自抓取一條含 ID 的合法請求
2. 用 A 的憑證重放 B 的 ID → 差分對照（200 + B 資料 = 成立）
3. 遍歷 ID +1/-1 確認可擴展性（不超過 3 條樣本）
紅線：樣本 1–3 條即停；禁碰他人敏感欄位；禁自動化全量遍歷
佐證：基線（A 自己的回應）+ 差分（A 存取 B 的回應）

## PB-02 未授權存取（案例基數 319）
觸發：API 路徑直達資源、管理後台路徑可達
步驟：
1. 抓登入前後請求對照，移除 Authorization/Cookie 重放
2. 403/401 → 嘗試 HTTP 方法替換（GET→POST）、路徑變體（/api/v1/ → /api/v2/）
3. 命中 200 + 敏感資料 = 成立
紅線：僅讀取證明；禁任何寫操作；命中即登記
佐證：匿名請求 200 的回應截圖（遮罩敏感欄位）

## PB-03 上傳 getshell → RCE（案例基數 385）
觸發：檔案上傳點（頭像/附件/匯入）
步驟：
1. 上傳雙副檔名/Content-Type 偽造/圖片馬
2. 定位儲存路徑（回顯/猜測/目錄列表）
3. 訪問執行驗證 → 僅 `id`/`whoami`
紅線：證明即停；禁破壞性命令；禁持久化
佐證：執行結果截圖 + 上傳請求全文

## PB-04 SQLi（案例基數 335）
觸發：搜尋/篩選/排序參數，報錯頁面含 SQL 片段
步驟：
1. 單引號閉合探測 → 布林對照（' AND 1=1 / ' AND 1=2）
2. UNION 探欄位 → information_schema 定位敏感表
3. 拿到庫名/表名即收
紅線：禁 dump；禁寫檔（file_priv）；禁 time-based 大量延遲爆破
佐證：布林差分截圖 + UNION 回顯

## PB-05 XSS（案例基數 335）
觸發：搜尋回顯、評論、個人資料欄位、URL 參數反射
步驟：
1. 標記探測 `jsqk<>"'` → 觀察編碼/過濾
2. 上下文適配（HTML/attr/JS/URL）構造最小 payload
3. `<svg/onload=marker()>` 或 `<img onerror>` 本地證明
紅線：僅 computed 標記；禁竊取 cookie 的真實外帶；禁打真實用戶
佐證：彈窗截圖 + 輸入輸出對照

## PB-06 SSRF（案例基數 280）
觸發：URL 預覽/webhook/匯入/匯出功能
步驟：
1. 外帶平臺（DNSLog）收 canon 命中
2. 內網位址探測（僅 169.254.169.254 / 127.0.0.1 / 內網 gateway ping）
3. 協議變體（file:// gopher:// dict://）僅測證明
紅線：禁內網橫向；禁讀內網敏感檔案；命中雲憑據線索即停並報告
佐證：DNSLog 回顯 + 請求響應對

## PB-07 資訊洩露（案例基數 319）
觸發：.git/.env/備份檔/debug 端點/目錄列表
步驟：
1. ffuf 探測常見洩露路徑（保守 wordlist）
2. .git → 還原 index 驗證可用性（本地操作）
3. .env → 按 infra-secrets.txt 模式提取
紅線：命中即停；禁下載全量；禁用洩露憑據登入（僅登記）
佐證：命中路徑 + 檔案頭部截圖（遮罩值）

## PB-08 邏輯漏洞（案例基數 260）
觸發：支付/優惠券/驗證碼/越權修改
步驟：
1. 金額/數量負數、溢位、精度攻擊（僅在測試環境或停於下單前）
2. 驗證碼重放/前端繞過（回包改寫僅本地驗證）
3. 狀態機跳步（未支付→已發貨探測）
紅線：禁真實下單付款；禁影響其他真實用戶；停於證明
佐證：請求重放對照 + 狀態異常截圖
