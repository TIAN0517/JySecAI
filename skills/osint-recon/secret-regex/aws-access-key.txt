# AWS Access Key Pattern
# Matches: AKIAIOSFODNN7EXAMPLE, aws_access_key_id, etc.
# Source: Claude-OSINT + adapted for JySecAI proxy_pool

# Pattern: AWS Access Key ID (20 characters, starts with AKIA or ASIA)
AWS_ACCESS_KEY_ID_REGEX   = (?i)(?:AWS_ACCESS_KEY_ID|aws_access_key_id|AWSAccessKeyId)\s*[:=]\s*['\"]?([A-Z0-9]{20})
AWS_ACCESS_KEY_AKIA_REGEX = AKIA[A-Z0-9]{16}
AWS_ACCESS_KEY_ASIA_REGEX = ASIA[A-Z0-9]{16}

# AI 驗證提示（命中後交給 hitl.audit_model 複核）
AWS_KEY_AI_PROMPT = 檢測到潛在 AWS Access Key。請驗證：1) 真實憑據或誤報？ 2) 影響範圍（單一資源 vs 全域）？ 3) 報告中需建議輪換？

# 落盤/遮罩規則
MASK_RULE = 前4位…後4位（例：AKIA…7X2Q），完整金鑰僅存 recon/<target-slug>/secrets-findings.md
