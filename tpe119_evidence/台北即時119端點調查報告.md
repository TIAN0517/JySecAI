## 1. 公開無認證 119 出勤 API (Verified Live 2026-09-21/22)

**Endpoint**: `POST https://service119.tfd.gov.tw/service119/citizenCase/caseList`

**認證**: **NONE** — 僅需 `Content-Type: application/x-www-form-urlencoded`, body: `t=<timestamp>`  
**回應**: JSON `{"total": N, "rows": [...]}`

### 回應字段說明

| 欄位 | 說明 | 例 |
|------|------|----|
| `inTime` | 案件時間 | `2026/09/21 01:26:36` |
| `dpKdid` | 派遣單位 | `A`, `B`, `C` |
| `csKindName` | 案件類別 | `救譫` (ambulance), `火灰` (fire) |
| `csPlace` | **完整地址** (條件性) | `臺北市士林區捷運劗潭站出口3` |
| `csPlaceFuzzy` | 模糊地址 (始終存在) | `臺北市士林區士東路` |
| `csX` / `csY` | **TWD97 座標** (條件性) | `302941.77`, `2775215.83` |
| `caseStatus` | 案件狀態 | `已派遣`, `到達現場`, `離開現場`, `返隊` |
