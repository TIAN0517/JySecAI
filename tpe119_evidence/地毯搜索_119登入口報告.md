## 階段 9: EPCR Auth Server 反向工程 (port 4004)

### 系統架構
- **AuthServer**: AngularJS SPA (ng-app="AuthServer"), port 4004
- **HospitalServer**: AngularJS SPA (ng-app="HospitalServer"), port 4002
- **EPCR 前端**: AngularJS SPA (ng-app="app"), port 4000
- 所有 JS 文件公開訪問 (無需認證), Auth Server 的 `js/app.js`、`js/AuthService.js`、`js/LoginCtrl.js`、`js/services.js` 全部可 GET

### 登入表單 (公開訪問)
- **URL**: `https://epcr.tpf.gov.tw:4004/templates/login.html` (200, 4064 bytes)
- **ng-model**: `credentials.username`, `credentials.password`, `credentials.captcha`
- **驗證碼**: `GET /captcha?t=<timestamp>` 返回 GIF200 圖片
- **提交**: `POST /login` with `{username, password, captcha, domain: 'AUTH_SERVER'}`
- **2FA**: `POST /login2FA` with `{userToken, domain: 'AUTH_SERVER'}`

### 登入嘗試結果 (POST /login)
- **空請求**: 500 "TypeError" (缺少參數導致伺服器錯誤)
- **admin:admin**: 403 `{"message":"無法登入的來源","code":403}` — **IP 白名單限制!**
- **SSO 登入**: `POST /sso/login` — 401 (無 Authorization token)
- **刷新 Token**: `POST /refreshToken` — 401

### JWT Token 結構
- **localStorage key**: `EPCRServerAuthToken` (port 4000), `AuthToken` (auth server port 4004), `HospitalAuthToken` (port 4002)
- **Payload**: `{ user: {role: string, ...}, permissions: [string, ...] }`
- **Header**: `Authorization: Bearer <JWT>`
- **Auto-refresh**: 401 自動重試 refresh token 機制

### RBAC 角色權限 (來自 js/permissionlist.js)
