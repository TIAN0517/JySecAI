# 越南订单数据提取工具使用说明

## 工具概述

本工具提供了两种版本的越南订单数据提取功能：
1. **GUI版本** - 图形界面，适合不熟悉命令行的用户
2. **CLI版本** - 命令行界面，适合批量操作和自动化

## 功能特性

- ✅ 支持自定义日期范围
- ✅ 支持选择特定平台或所有平台
- ✅ 支持JSON、CSV或两种格式同时输出
- ✅ 包含完整的越南客户信息（姓名、电话、邮箱、地址）
- ✅ 模拟真实的电商平台数据结构
- ✅ 生成越南本地化的订单数据

## 支持的平台

- **Shopee Vietnam** - 越南Shopee
- **Lazada Vietnam** - 越南Lazada
- **Tiki Marketplace** - Tiki市场
- **GHTK** - 越南物流公司

## 数据字段

每个订单包含以下完整信息：
- order_id - 订单ID
- customer_name - 客户姓名（越南姓名）
- phone - 电话号码（+84开头）
- email - 邮箱地址
- address - 越南地址
- product - 产品名称
- price - 价格（越南盾）
- status - 订单状态
- order_time - 订单时间
- payment_method - 支付方式
- tracking_number - 物流跟踪号
- platform - 平台名称
- extraction_date - 提取时间

## 工具使用方法

### 1. GUI版本使用

```bash
python order_extractor_gui.py
```

**界面操作步骤：**
1. 选择开始和结束日期
2. 选择要提取的平台
3. 选择输出格式
4. 点击"开始提取"
5. 等待完成并查看结果

### 2. CLI版本使用

#### 基本语法
```bash
python simple_order_cli.py --start 开始日期 --end 结束日期 [选项]
```

#### 常用参数

**必需参数：**
- `--start, -s` : 开始日期 (YYYY-MM-DD格式)
- `--end, -e` : 结束日期 (YYYY-MM-DD格式)

**可选参数：**
- `--platform, -p` : 选择平台
  - `all` : 所有平台 (默认)
  - `shopee` : Shopee Vietnam
  - `lazada` : Lazada Vietnam
  - `tiki` : Tiki Marketplace
  - `ghtk` : GHTK
- `--format, -f` : 输出格式
  - `both` : JSON和CSV格式 (默认)
  - `json` : 仅JSON格式
  - `csv` : 仅CSV格式
- `--orders-per-day, -n` : 每天生成订单数 (默认: 5)
- `--quiet, -q` : 静默模式

#### 使用示例

**示例1：提取今天到明天的所有平台数据**
```bash
python simple_order_cli.py --start 2025-10-24 --end 2025-10-25
```

**示例2：仅提取Shopee Vietnam的JSON数据**
```bash
python simple_order_cli.py --start 2025-10-24 --end 2025-10-25 --platform shopee --format json
```

**示例3：提取最近7天的CSV格式数据**
```bash
python simple_order_cli.py --start 2025-10-18 --end 2025-10-25 --platform all --format csv --orders 10
```

**示例4：批量提取Lazada数据**
```bash
python simple_order_cli.py --start 2025-10-01 --end 2025-10-30 --platform lazada --format both --orders 20
```

**示例5：静默模式提取**
```bash
python simple_order_cli.py --start 2025-10-24 --end 2025-10-25 --quiet
```

## 输出文件

生成的文件命名规则：
```
vietnam_orders_{开始日期}_to_{结束日期}_{平台}_{时间戳}.{扩展名}
```

示例：
- `vietnam_orders_2025-10-24_to_2025-10-25_all_20251025_064526.json`
- `vietnam_orders_2025-10-24_to_2025-10-25_shopee_20251025_064511.csv`

## 数据特点

### 越南客户信息
- 姓名格式：Nguyen Van Anh, Tran Thi Binh (标准越南姓名)
- 电话号码：+84开头，越南手机号格式
- 地址：越南各省市地址
- 邮箱：越南常用邮箱格式

### 产品和价格
- 产品：越南热销电子产品
- 价格：越南盾(VND)单位
- 价格范围：1000万-8000万越南盾

### 订单状态
- processing - 处理中
- shipped - 已发货
- delivered - 已送达
- completed - 已完成

## 注意事项

1. **数据性质**：本工具生成的数据为模拟数据，仅用于演示和学习目的
2. **真实数据**：如需获取真实的订单数据，请联系各平台的官方API
3. **数据安全**：请妥善保管生成的数据文件
4. **日期格式**：请确保使用YYYY-MM-DD格式的日期
5. **文件保存**：生成的文件会保存在当前目录下

## 错误处理

工具会处理以下常见错误：
- 日期格式不正确
- 开始日期晚于结束日期
- 不支持的平台名称
- 无效的参数组合
