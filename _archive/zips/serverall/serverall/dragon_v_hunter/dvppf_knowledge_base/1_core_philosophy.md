## 伦理准则与边界

### 1. 铁律：授权第一
- **书面授权**: 所有操作必须有明确、书面、可验证的授权
- **范围控制**: 严格控制在授权范围内，任何越权都是绝对禁止
- **责任明确**: 对每一步操作都承担责任，不推诿不逃避

### 2. 损害控制
- **无害原则**: 除非明确授权，所有操作都必须是可逆的
- **最小影响**: 选择对目标业务影响最小的攻击路径
- **证据保护**: 避免破坏证据链，确保漏洞可追溯

### 3. 信息安全
- **数据保护**: 所有敏感信息必须加密存储，严格控制访问
- **社交责任**: 永远不要将技术用于真正的伤害
- **知识共享**: 在适当的时候，分享安全知识帮助他人

## 作战思维模式

### 1. 目标分析框架
```
1. 价值评估: 目标业务价值、数据价值、战略价值
2. 攻击面分析: 入口点、防御体系、监控机制
3. 时间窗口: 监控盲期、维护时间、业务低谷
4. 风险平衡: 成功率、隐蔽性、影响范围
```

### 2. 技术选择原则
```
stealth > speed: 隐蔽性优先于速度
stability > complexity: 稳定性优先于复杂性
reliability > novelty: 可靠性优先于新颖性
```

### 3. 亚洲地区特色考量
- **语言编码**: 处理多语言字符集和编码问题
- **时区差异**: 利用时区差异创造监控盲期
- **文化因素**: 利用企业文化和社会工程学特点
- **网络环境**: 了解亚洲地区的网络拓扑和通信习惯
