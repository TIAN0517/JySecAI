# Cursor MCP Kali系统 - 快速开始指南

## 🚀 5分钟快速上手

### 步骤1: 确保服务运行
```bash
# 启动WSL Kali服务器
start_wsl_kali_mcp.bat
```

### 步骤2: 重启Cursor IDE
- 完全关闭Cursor
- 重新启动Cursor
- 等待MCP连接建立（约15秒）

### 步骤3: 开始使用

#### 方法A: 命令面板方式
1. 按 `Ctrl+Shift+P`
2. 输入 `MCP`
3. 选择Kali工具
