## 🔧 故障排除

### 连接问题
1. 检查WSL服务器：`curl http://localhost:5001/health`
2. 重启MCP客户端：`python mcp_server.py --server http://localhost:5001`
3. 重启Cursor IDE

### 工具不可用
1. 运行：`install_missing_tools.bat`
2. 检查工具安装状态
3. 重启服务器

### 权限问题
使用sudo权限（密码：520520）：
```cursor
使用sudo权限执行系统扫描
```
