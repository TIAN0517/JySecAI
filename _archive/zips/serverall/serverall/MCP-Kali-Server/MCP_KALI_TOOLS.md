## 🔧 可用工具详解

### 1. Nmap (网络映射器)
**功能**: 网络发现和安全审计
**状态**: ✅ 完全可用

#### 基本用法
```cursor
请扫描192.168.1.1的常用端口
```

#### 高级选项
```cursor
使用nmap对target.com进行以下扫描：
- 端口范围: 1-1000
- 扫描类型: -sS (SYN扫描)
- 脚本扫描: 默认脚本
- 版本检测: -sV
- OS检测: -O
```

#### 扫描类型
- **端口扫描**: 发现开放端口
- **服务识别**: 检测运行的服务和版本
- **OS检测**: 识别操作系统类型
- **脚本扫描**: 使用NSE脚本进行漏洞检测

### 2. SQLMap (SQL注入工具)
**功能**: 自动化SQL注入和数据库接管
**状态**: ✅ 完全可用

#### 基本用法
```cursor
测试http://example.com/login的SQL注入漏洞
```

#### 高级选项
```cursor
使用sqlmap对http://target.com/page.php?id=1进行：
- 数据库指纹识别
- 当前用户检测
- 数据库枚举
- 表结构发现
- 数据提取
```

#### 支持的注入技术
- **Boolean盲注**
- **时间盲注**
- **Error-based注入**
- **Union查询注入**
- **Stacked queries**
