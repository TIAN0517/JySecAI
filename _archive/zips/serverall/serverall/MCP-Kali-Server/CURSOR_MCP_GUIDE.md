# Cursor MCP Kali系统使用指南

## 🚀 快速开始

### 1. 确保系统运行
```bash
# 1. 启动WSL Kali服务器
start_wsl_kali_mcp.bat

# 2. 确认服务状态
curl http://localhost:5001/health
```

### 2. 启动Cursor
- 重启Cursor IDE以加载MCP配置
- 等待MCP连接建立（约10-15秒）

## 🎯 在Cursor中使用MCP工具

### 方法1: 通过命令面板
1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 `MCP` 查看可用工具
3. 选择需要的Kali工具

### 方法2: 直接与AI对话
在聊天框中直接告诉AI要执行的操作：

```
请使用nmap扫描192.168.1.1的常用端口
```

```
请使用sqlmap测试http://example.com/login的SQL注入漏洞
```

## 🛠️ 可用的MCP工具

### 网络扫描工具
- **nmap_network_scanner**: 网络端口扫描和服务识别
- **hydra_password_cracker**: 在线密码暴力破解

### Web应用测试
- **sqlmap_sql_injection**: SQL注入漏洞检测和利用
- **nikto_web_scanner**: Web服务器漏洞扫描

### 目录爆破
- **gobuster_directory_bruteforce**: 目录和文件爆破
- **dirb_directory_scanner**: 目录扫描

### 系统枚举
- **enum4linux_smb_enumeration**: SMB服务枚举
- **wpscan_wordpress_scanner**: WordPress安全扫描

## 📝 实际使用示例

### 示例1: 网络扫描
```
用户: 请扫描目标网络192.168.1.0/24的活跃主机和开放端口

AI: 我将使用nmap网络扫描工具来扫描指定网络段...

[执行nmap扫描命令]

扫描结果：
- 192.168.1.1 - 开放端口: 22(SSH), 80(HTTP)
- 192.168.1.100 - 开放端口: 80(HTTP), 443(HTTPS)
- 192.168.1.105 - 开放端口: 22(SSH), 3306(MySQL)
```

### 示例2: SQL注入测试
```
用户: 测试这个登录页面是否存在SQL注入漏洞: http://testphp.vulnweb.com/listproducts.php?cat=1

AI: 我将使用sqlmap来测试该URL的SQL注入漏洞...

[执行sqlmap测试]

测试结果：
- 发现参数'cat'存在基于时间的盲注漏洞
- 数据库类型: MySQL
- 可以提取数据库信息
```

### 示例3: 目录爆破

```
用户: 对http://example.com进行目录和文件发现

AI: 我将使用gobuster工具来发现隐藏的目录和文件...

[执行gobuster扫描]

发现的内容：
/admin - Status: 200
/backup - Status: 403
/config.php.bak - Status: 200
/uploads - Status: 200
```

### 自定义扫描参数
您可以指定具体的扫描参数：

```
请使用nmap对192.168.1.100进行以下扫描：
- 端口范围: 1-1000
- 扫描类型: SYN扫描
- 脚本扫描: 默认脚本
- 保存结果到文件
```

### 批量目标扫描
```
请扫描以下多个目标：
- 192.168.1.1:80
- 192.168.1.100:443
- example.com:22
```

```
建议的修复措施：
[详细的修复建议]
```

## 🔧 配置和故障排除

### 检查MCP连接状态
1. 在Cursor中按 `Ctrl+Shift+P`
2. 输入 `MCP: Show Status`
3. 查看连接状态和可用工具

### 常见问题解决

#### 问题1: MCP工具不可用
**解决方案:**
1. 检查WSL Kali服务器是否运行
2. 重启Cursor IDE
3. 检查配置文件路径

#### 问题2: 工具执行失败
**解决方案:**
1. 检查网络连接
2. 确认目标可达性
3. 检查权限设置

#### 问题3: 权限不足
**解决方案:**
1. 某些操作需要管理员权限
2. 检查WSL sudo配置
3. 使用密码: 520520

## 🔒 安全注意事项

1. **合法使用**: 仅在授权环境中使用
2. **数据保护**: 妥善处理扫描发现的敏感信息
3. **网络影响**: 扫描可能影响网络性能
4. **日志记录**: 所有操作都会被记录
