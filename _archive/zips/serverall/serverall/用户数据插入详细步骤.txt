🔧 Dast-Xray 用户数据插入详细步骤

📋 当前状态：
✅ 后端服务运行在端口 8092
✅ 前端服务运行在端口 9536
✅ H2数据库控制台已打开
❌ 需要手动插入用户数据

🎯 解决方案：通过H2控制台插入用户数据

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📖 详细操作步骤：

🔹 步骤 1：打开H2控制台
   ✅ 已自动打开：http://localhost:8092/h2-console
   如果没有自动打开，请手动访问上述地址

🔹 步骤 2：配置数据库连接
   在H2控制台页面中填写以下信息：

   ┌─────────────────────────────┐
   │ JDBC URL:                  │
   │ jdbc:h2:mem:testdb       │
   │                           │
   │ User Name:                │
   │ sa                        │
   │                           │
   │ Password:                 │
   │ (留空/保持空白)           │
   └─────────────────────────────┘

   ✅ 点击"Connect"按钮连接数据库

🔹 步骤 3：检查表结构
   在SQL查询框中输入以下命令检查用户表：

   SELECT * FROM users;

   - 如果显示"0 rows"或"No rows selected"，说明表存在但没有数据
   - 如果显示错误，先创建表（见下方的备用步骤）

🔹 步骤 4：插入管理员用户数据
   在SQL查询框中复制以下完整SQL语句：

   INSERT INTO users (id, username, password)
   VALUES ('admin', 'admin', '29060b04c2974e430c23bef014664087');

   ✅ 点击"Run"按钮执行
   ✅ 成功提示应该显示"1 row affected"

🔹 步骤 5：验证数据插入
   在SQL查询框中输入：

   SELECT * FROM users WHERE username = 'admin';

   ✅ 点击"Run"按钮
   ✅ 应该看到一行数据，包含：
   - id: admin
   - username: admin
   - password: 29060b04c2974e430c23bef014664087

🔹 步骤 6：测试登录
   ✅ 打开登录页面：http://localhost:9536
   ✅ 使用以下凭据登录：
      • 用户名: admin
      • 密码: Ss520520@@

🔹 步骤 7：登录成功验证
   ✅ 如果登录成功，系统会跳转到主页面
   ✅ 可以开始使用Dast-Xray漏洞扫描功能

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 备用步骤（如果users表不存在）：

如果步骤3显示表不存在错误，请先创建表：

CREATE TABLE IF NOT EXISTS users (
    id VARCHAR(50) PRIMARY KEY,
    username VARCHAR(100) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL
);

然后继续执行步骤4-7。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️ 重要提醒：

1. H2是内存数据库，每次重启后端服务，数据都会丢失
2. 如果重启后无法登录，需要重复执行步骤4-5
3. 确保后端服务(8092)和前端服务(9536)都在运行
4. 密码的MD5哈希值是：29060b04c2974e430c23bef014664087

🔍 故障排除：

- 如果H2控制台无法访问，检查后端服务是否运行
- 如果SQL执行失败，检查SQL语法是否正确
- 如果登录仍然失败，确认用户数据是否正确插入
