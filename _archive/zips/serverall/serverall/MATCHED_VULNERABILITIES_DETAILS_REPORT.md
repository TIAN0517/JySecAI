### 1. CVE-2020-26232 - Jupyter Server 开放重定向

**基本信息**:
- **CVE ID**: CVE-2020-26232
- **严重程度**: MEDIUM
- **匹配分数**: 2.40
- **影响产品**: jupyter-server

**漏洞描述**:
Jupyter Server 中存在开放重定向漏洞，允许恶意构造的链接将浏览器重定向到不同的网站。虽然所有 Jupyter 服务器在技术上都会受到影响，但这种链接只能针对已知的 Jupyter 服务器主机合理地制作，可能导致用户被引导到公共互联网上的欺骗服务器。

**CVSS 评分**:
- **向量**: CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:N/I:L/A:N
- **基础分数**: 0.0 (由于配置问题，实际应为中等风险)

**解决方案**:
1. 升级到 jupyter-server 1.0.6 或更高版本
2. 审查并验证所有外部链接，确保它们不指向不受信任的域
3. 实施额外的安全措施，如内容安全策略 (CSP) 来减轻开放重定向的风险

### 2. CVE-2022-24757 - Jupyter Server 信息泄露

**基本信息**:
- **CVE ID**: CVE-2022-24757
- **严重程度**: HIGH
- **匹配分数**: 2.40
- **影响产品**: jupyter-server

**漏洞描述**:
每当触发 5xx 错误时，认证 cookie 和其他标头值会默认记录在 Jupyter Server 日志中。考虑到这些日志不需要 root 访问权限，攻击者可以监控这些日志，窃取敏感的认证/cookie 信息，并获得对 Jupyter 服务器的访问权限。

**CVSS 评分**:
- **向量**: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N
- **基础分数**: 0.0 (配置问题，实际应为高风险)

**解决方案**:
1. 升级到 Jupyter Server 1.15.4 或更高版本
2. 监控并限制对 Jupyter Server 日志的访问，防止未经授权的信息泄露
