================================================================================
                     第一步: 启用防火墙 (2分钟)
================================================================================

【打开】PowerShell (以管理员身份运行)

【执行】以下命令:

  netsh advfirewall set allprofiles state on

【验证】防火墙已启用:

  netsh advfirewall show allprofiles

【预期结果】显示 "State                                 ON"

================================================================================
                   第二步: 关闭危险端口 (3分钟)
================================================================================

【执行】以下 PowerShell 命令:

  netsh advfirewall firewall add rule name="Block FTP" dir=in action=block protocol=tcp localport=21
  netsh advfirewall firewall add rule name="Block Telnet" dir=in action=block protocol=tcp localport=23
  netsh advfirewall firewall add rule name="Block TFTP" dir=in action=block protocol=tcp localport=69

【验证】端口已阻止:

  netstat -ano | findstr "LISTENING" | findstr ":21"

【预期】没有输出 = 成功关闭

================================================================================
                   第三步: 启用 Windows Update (1分钟)
================================================================================

【执行】以下 PowerShell 命令:

  Start-Service -Name wuauserv
  Set-Service -Name wuauserv -StartupType Automatic

【验证】:

  Get-Service -Name wuauserv

【预期】Status 显示 "Running"

================================================================================
                        第四步: 验证修复 (5分钟)
================================================================================

【执行】重新运行审计工具:

  cd C:\Users\Administrator\Desktop\serverall
  python network_security_audit.py

【查看输出】:
  - 防火墙状态: 应该显示 "ON" ✓
  - 开放端口: 应该少于 80 个
  - 安全评分: 应该大于 60

================================================================================
                          第五步: 后续配置
================================================================================

如果前4步都完成，您的系统已大幅改进！

接下来可以考虑：

1. 审计所有开放端口 (执行更深度的扫描)
   命令: Get-NetTCPConnection -State Listen | Select-Object LocalPort | Sort-Object LocalPort -Unique

2. 禁用不必要的服务 (如 WinRM)

         Account Policies > Password Policy

================================================================================
                           故障排除
================================================================================

问题 1: 无法运行 PowerShell 命令
解决: 
  - 右键单击 PowerShell -> "以管理员身份运行"
  - 如果显示"访问被拒绝"，检查是否真的是管理员权限

问题 2: 防火墙启用后网络无法连接
解决:
  - 这是正常的 - 防火墙可能需要添加规则
  - 运行: netsh advfirewall firewall add rule name="Allow DNS" dir=out action=allow protocol=udp remoteport=53
  - 或在防火墙 GUI 中添加例外

问题 3: 审计工具显示权限不足
解决:
  - 以管理员身份运行 PowerShell
  - 然后运行: python network_security_audit.py
