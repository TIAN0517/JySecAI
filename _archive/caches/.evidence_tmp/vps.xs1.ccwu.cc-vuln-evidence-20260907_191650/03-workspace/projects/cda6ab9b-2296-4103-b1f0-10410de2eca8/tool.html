開啟 Admin 如何接

如何接入

下列指令以一台已安裝 Claude Code 的開發者機器為準。Bearer token 請向 digital@tzuchi.org.tw 申請；token 視為機密，請勿提交到 repo。

# drust — 開 Admin UI 拿 token，再貼進 Claude Code

每個租戶在 Admin UI 都有「Copy MCP config」按鈕，內含正確的 URL 和 service key，直接貼進 Claude Code 即可：

# 1. 在瀏覽器開：
https://tool.tzuchi-org.tw/drust/admin/tenants/<tenant>/_api_keys

# 2. 點「Copy MCP config」，貼到 terminal：
claude mcp add-json drust-<tenant> '<貼上的 JSON>'

# youtube — 直接打 HTTP，無認證

curl 'https://tool.tzuchi-org.tw/youtube/playlist?list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab'

回傳 JSON 結構：{ playlist: {...}, videos: [...] }。詳細欄位語意見服務原始碼 youtube/CLAUDE.md（內網）。

# tracking — Streamable HTTP MCP，bearer 認證

claude mcp add-json tracking '{
  "type": "streamable-http",
  "url": "https://tool.tzuchi-org.tw/tracking/mcp",
  "headers": { "Authorization": "Bearer <TOKEN>" }
}'

接好之後，在 Claude Code 內用 /mcp 應該看到 tracking 出現，4 個工具都可用。

架構簡圖：browser → .221 nginx (TLS) → :8793 Caddy → 127.0.0.1:<port>
每個服務都用 handle_path /<name>/* 路由；MCP 服務需 header_up Host 覆寫（rmcp DNS rebinding 防護）。
