# 缺少安全头部 - X-Frame-Options

- ID: `5264ca1e-f9c3-400f-a27c-2e401a76cf72`
- Severity: **low**
- Status: open
- Type: Missing Security Header
- Target: `https://www.letsmakeaplan.org`
- Conversation: `c97e5501-e87e-41a7-8a52-050bc6f5acf3`
- Created: 2026-09-07 03:43:58.563556013+08:00

## Description

网站响应头中缺少X-Frame-Options头部，这可能导致点击劫持攻击。

## Reproduction

1. 访问 https://www.letsmakeaplan.org\n2. 检查响应头中的X-Frame-Options字段\n3. 发现该头部缺失

## Evidence

响应头中未包含X-Frame-Options头部，虽然网站设置了x-frame-options: SAMEORIGIN，但这种设置可能存在不一致性。

## Impact

攻击者可能利用此漏洞通过iframe嵌入页面，实施点击劫持攻击，诱导用户在不知情的情况下执行操作。

## Recommendation

1. 在所有响应中添加X-Frame-Options头部\n2. 设置为DENY或SAMEORIGIN\n3. 考虑使用Content-Security-Policy头部增强防护
