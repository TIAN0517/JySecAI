## Description

GET /events 端点无需任何认证即可访问，返回 567201 条医疗事件数据（JSON 数组），包含 CaseID、recordUuid、时间戳、类型、生命体征（血压）等敏感信息。数据涵盖 2018 年至今的 PCDT（运动压力测试）记录。

## Reproduction

1. 发送 GET 请求：`curl -sk "https://epcr.tpf.gov.tw:4001/events?range=0-10"`
2. 观察响应：HTTP 200 OK
3. 检查 content-range 头：`items 0-99/567201`
4. 解析 JSON 数组：包含 CaseID、recordUuid、Timestamp 等敏感字段
5. 遍历分页：`?range=0-9999` 批量下载

关键泄露字段：

- **recordUuid**: 记录 UUID（如 Test180805142701）

- **TypeOfEventTxt**: 事件类型（startofPCDT、endofPCDT、mark、learningRhythm）

- **Elapsed**: 持续时间（毫秒）
- **createdAt/updatedAt**: 创建/更新时间

## Impact

**高** - 大规模医疗数据泄露：
1. **567,201 条记录**：覆盖 2018-2026 年的 PCDT 运动压力测试
2. **患者识别**：通过 CaseID 和 recordUuid 可识别患者
3. **时间线重建**：通过 Timestamp 可重建患者就诊时间线
4. **生命体征**：血压数据可评估患者健康状况
5. **事件类型**：PCDT 开始/结束、标记、学习节奏等
6. **数据量**：约 47KB/100 条，总计约 270MB 数据

结合 /config 泄露的服务拓扑，攻击者可：
- 批量下载所有事件数据
- 分析特定患者的历史 PCDT 记录
- 发现血压异常模式
- 关联其他服务（如 4002 HospitalServer、4003 doctorServer）

## Recommendation

1. **添加认证**：要求 JWT Bearer Token
2. **分页限制**：默认返回少量数据，限制最大分页大小
3. **速率限制**：防止批量下载
4. **数据脱敏**：返回前对患者标识符脱敏
5. **访问日志**：记录所有访问
6. **添加缓存**：减少数据库压力
