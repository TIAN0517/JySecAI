## Description

EPCR 电子公文/急救病历（AngularJS + Nginx + Ubuntu）。扫描器由项目事实 target/epcr_main 生成本条。
对外入口 118.163.107.93:4000，前端 hostname 指向 epcr.tpf.gov.tw。
本条是信息泄露/攻击面测绘，不是已验证的 RCE 或越权。
已用本地落地的 index.html 与 PUBLIC_CONFIG 交叉验证 Maps Key 与 4001-4008/9000 端口清单。
CSP 中的 35.234.50.28:8100/18081 仅见扫描摘要，前端常量未见，标待确认。
未对目标做活站利用。

## Preconditions

1. 能访问 EPCR 登录页或会加载 index.html / publicConfig 的入口。
2. 静态 JS 可匿名读取（是否全站匿名可读待确认）。

## Reproduction

1. 打开 http://118.163.107.93:4000/ 或 https://epcr.tpf.gov.tw
2. 查看 index.html 中 maps.google.com/maps/api/js?key=
3. 查看 PUBLIC_CONFIG（vitalSignVideoServer/authServer/printServer 等）
4. 对照响应头 Content-Security-Policy（扫描器称含内部端口与 35.234.50.28）
5. 管理口 OpenSSH_8.2p1 监听 2222（仅版本暴露记录）

## Impact

中危信息泄露。浏览器侧完整微服务拓扑缩小后续测试范围；Maps Key 若未限制 Referrer 可被盗刷配额；列印/监控/MCI 为明文 http。
未证明越权或 RCE。若 4001-4008/9000/2222 对公网开放应升级。政务急救病历，面扩大后隐私影响高。

## Recommendation

1. PUBLIC_CONFIG 改为相对路径或同源反代，不要把 4001-4008/9000/内部主机名写进浏览器 JS
2. Maps Key 限制 HTTP Referrer 为业务域名，关闭多余 API，轮换已泄露 Key
3. CSP 只写当前源，删除 GCP 内网 IP 与调试口
4. printServer/epcrServer/mciServer/monitorServer 不要用 http://
5. SSH 收进管理网/VPN，对外不要暴露 2222 banner
6. AngularJS 已 EOL，中长期迁栈
