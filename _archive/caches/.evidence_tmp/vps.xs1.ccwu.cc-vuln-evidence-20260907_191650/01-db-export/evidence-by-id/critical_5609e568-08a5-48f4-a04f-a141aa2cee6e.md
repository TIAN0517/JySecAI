## Description

端口 4008 上 LoopBack v4 风格 REST 端点 `/MciTypes`（MCI 大傷事件类型字典）**未授权写路径**：无需任何认证 token 即可通过 POST 创建任意 MciType 记录，自动递增 id。可用于植入 Stored XSS、SSTI、SQLi payload 到生产字典表，污染临床决策数据 + 钓鱼管理员/医生浏览器（执行 `<script>` 窃 cookie 或 `{{constructor.constructor(...)()}}` 实现模板注入 RCE）。
模型类名 `MciType`、必填字段 `name`、额外字段 `isValid`（可见：POST 时仅设置 name 也会成功）。X-HTTP-Method-Override: GET + 空 body 直接进入 ORM 不触发认证。
在已泄露的 25 条记录中已发现 21 条攻击者历史 payload（XSS/SSTI/SQLi/BOLA/认证测试/强制 ID 测试/本会话期间 2026-08-29 持续写入），表明该写路径长期开放且未清理。

## Preconditions

无需认证（无 JWT、无 cookie、无 IP 白名单）；直接对 `https://epcr.tpf.gov.tw:4008/MciTypes` 发 POST 请求即可。

## Reproduction

1. curl -X POST https://epcr.tpf.gov.tw:4008/MciTypes -H "Content-Type: application/json" -d '{"name":"PENTEST_PROBE_MCITYPES_001","isValid":true}'
2. 观察响应：HTTP 201 Created + Location: /MciTypes/1000018 + Body 含 {"id":1000018,"name":"PENTEST_PROBE_MCITYPES_001",...}
3. 立即 GET https://epcr.tpf.gov.tw:4008/MciTypes 验证：响应 content-range items 0-99/N+1，列表新增第 N+1 条。

## Impact

**极高危**：
1. 任意攻击者可无认证植入 Stored XSS payload 到生产字典；管理员/医生在 MCI 调度界面查看 MciType 时会触发 `<script>` 执行 → 钓鱼、窃 cookie、会话劫持、内网渗透。
2. 若前端 AngularJS 1.x 使用 `{{ }}` 模板或无沙箱化 SSTI 解析器，植入 `{{constructor.constructor(...)()}}` 可导致 RCE。
3. 字典污染直接影响临床决策（救护车调度依据 MciType 分级）。
4. 长期开放写路径表明攻击者已多次成功写入但未被检测/清理，本会话期间(2026-08-29)仍持续被打。

## Recommendation

立即在 `/MciTypes` POST 路由前添加 JWT 鉴权中间件（与全局其他资源一致的 express-jwt/LoopBack 认证策略）；同时清理已写入的 21+ 条历史 payload；对 MciTypes 模型层强制 `name` 字段 HTML/模板转义与白名单校验；启用严格的 Content-Type 校验，禁止空 body 触发 ORM；部署 WAF 拦截 MongoDB 操作符（`$ne`、`$regex`、`$where`、`$function` 等）防止注入升级。
