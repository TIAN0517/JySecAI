# 4004 /captcha CORS 白名单偏松，Access-Control-Allow-Credentials 无条件返回

- ID: `2f20cd51-ac72-4ce8-9b4b-7b46a29e5b5e`
- Severity: **low**
- Status: open
- Type: CORS 配置缺陷
- Target: `https://epcr.tpf.gov.tw:4004/captcha`
- Conversation: `9f0a20d8-98b0-4f97-8e49-573ac9d822dc`
- Created: 2026-09-01 07:46:34.865791372+08:00

## Description

4004 authServer 的 /captcha 端点对合法 Origin https://epcr.tpf.gov.tw:4004 反射 Access-Control-Allow-Origin + Access-Control-Allow-Credentials: true，但对任意 Origin（如 attacker.example.com）也回 Access-Control-Allow-Credentials: true（虽无 Allow-Origin 反射），说明 CORS 配置偏松。若白名单逻辑有缺陷（如前缀匹配），攻击者可构造子域或同域 Origin 触发反射，实现跨域读取 captcha 图片。

## Preconditions

公网可达 https://epcr.tpf.gov.tw:4004

## Reproduction

1. curl -sk -D - 'https://epcr.tpf.gov.tw:4004/captcha' -H 'Origin: https://epcr.tpf.gov.tw:4004'
2. 观察 Access-Control-Allow-Origin + Access-Control-Allow-Credentials: true
3. curl -sk -D - 'https://epcr.tpf.gov.tw:4004/captcha' -H 'Origin: https://attacker.example.com'
4. 观察 Access-Control-Allow-Credentials: true 但无 Allow-Origin
5. 构造子域 Origin（如 epcr.tpf.gov.tw:4004.evil.com）测试是否触发反射

## Evidence

curl -sk -D - 'https://epcr.tpf.gov.tw:4004/captcha' -H 'Origin: https://epcr.tpf.gov.tw:4004' 返回 Access-Control-Allow-Origin: https://epcr.tpf.gov.tw:4004 + Access-Control-Allow-Credentials: true；curl -sk -D - 'https://epcr.tpf.gov.tw:4004/captcha' -H 'Origin: https://attacker.example.com' 返回 Access-Control-Allow-Credentials: true 但无 Allow-Origin

## Impact

CORS 白名单偏松，若存在前缀匹配或同域匹配缺陷，攻击者可构造 Origin（如 epcr.tpf.gov.tw:4004.evil.com）触发反射，实现跨域读取 captcha 图片，配合登录爆破可绕过验证码；Access-Control-Allow-Credentials: true 允许携带 cookie，若 Origin 反射成功可跨域窃取会话。

## Recommendation

收紧 CORS 白名单到精确匹配（如仅 https://epcr.tpf.gov.tw:4004）；对 Access-Control-Allow-Credentials 做条件返回（仅白名单 Origin 才回 true）；增加 Origin 白名单校验逻辑（如精确字符串匹配）。
