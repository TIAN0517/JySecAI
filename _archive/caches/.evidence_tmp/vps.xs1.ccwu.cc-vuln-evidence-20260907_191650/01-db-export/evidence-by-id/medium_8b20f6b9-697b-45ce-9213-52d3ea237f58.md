# 4004 /ssoLogin 仅需 sessionId 换 JWT，无认证可达且无速率限制

- ID: `8b20f6b9-697b-45ce-9213-52d3ea237f58`
- Severity: **medium**
- Status: open
- Type: 认证绕过 / 会话固定
- Target: `https://epcr.tpf.gov.tw:4004/ssoLogin`
- Conversation: `9f0a20d8-98b0-4f97-8e49-573ac9d822dc`
- Created: 2026-09-01 04:38:10.979591135+08:00

## Description

4004 authServer 的 /ssoLogin 端点仅需 {sessionId} 即可换取 JWT（源码 AuthService.js 证实无密码字段）。当前无认证 POST 可达并返回结构化 403 错误，说明端点暴露且无速率限制/CSRF 防护。若 sessionId 可枚举或可被劫持，攻击者可绕过密码直接获取 JWT，形成认证绕过。

## Preconditions

公网可达 https://epcr.tpf.gov.tw:4004

## Reproduction

1. curl -sk -X POST 'https://epcr.tpf.gov.tw:4004/ssoLogin' -H 'Content-Type: application/json' -d '{"sessionId":"test"}'
2. 观察返回 403 JSON 错误（非 401/404），说明端点可达且解析 sessionId
3. 替换 sessionId 为真实值（从 sportal 或其他 SSO 入口获取），若返回 200 + JWT 则认证绕过成功

## Evidence

curl -sk -X POST 'https://epcr.tpf.gov.tw:4004/ssoLogin' -H 'Content-Type: application/json' -d '{"sessionId":"test"}' 返回 HTTP 403，body {"name":"ErrorWithStatusCode","message":"無法辨識使用者","code":403}，Set-Cookie: connect.sid=s%3A...（无认证即可触发）

## Impact

若 sessionId 生成熵不足或可被枚举，攻击者可批量 POST /ssoLogin 获取合法用户 JWT，进而访问 /Pcrs/pcrCaseList 等受保护页面，形成完整认证绕过链。当前已确认端点暴露且无速率限制，爆破成本低。

## Recommendation

给 /ssoLogin 增加速率限制与 CSRF token；对 sessionId 做一次性消费与过期控制；若可能，增加签名或 HMAC 校验，避免仅凭 sessionId 换 JWT。
