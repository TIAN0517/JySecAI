- Type: 未授权访问/敏感资料外泄
- Target: `https://epcr.tpf.gov.tw:4001/videoData, https://epcr.tpf.gov.tw:4001/imageData, https://epcr.tpf.gov.tw:4001/socket.io`
- Conversation: `0e6944a5-643d-4cd9-9a2a-7b1676a25139`
- Created: 2026-09-06 15:06:26.37366837+08:00

## Description

4001 VitalSignVideoServer（https://epcr.tpf.gov.tw:4001）多个 REST 数据集合完全未启用认证：GET /videoData（急救影音，每页100条）与 GET /imageData（影像，每页100条，含"心電圖" ECG 图片）均可匿名列出与按主键读取（/videoData/{id}、/imageData/{id}）。记录字段含 recordUuid（案件 UUID）、CaseID、fileName（暴露 iPhone 设备 UUID 如 tw.com.viewlead.emtapp9C372D5A-...）、mimeType、ImageType/VideoType（如"心電圖"、"手機上傳"、"HeadCam"）、时间戳。这些是 EMS 急救患者的心电/影音个人健康资料。此外 socket.io 实时通道 /socket.io/ 无需认证即可握手取得 sid（EIO=3 polling 返回 200），且整站 Access-Control-Allow-Origin: *。

## Reproduction

1. curl -sS -k "https://epcr.tpf.gov.tw:4001/videoData?limit=1"（无需 token/cookie）→ HTTP 200，JSON 数组（每页100条，含 recordUuid/fileName/设备UUID）。
2. curl -sS -k "https://epcr.tpf.gov.tw:4001/imageData?limit=1" → HTTP 200，含 ImageType "心電圖"。
3. curl -sS -k "https://epcr.tpf.gov.tw:4001/videoData/107" → HTTP 200 单条。
4. curl -sS -k "https://epcr.tpf.gov.tw:4001/socket.io/?EIO=3&transport=polling" → HTTP 200 返回 sid（匿名握手成功）。

## Impact

未授权访问者可枚举并读取 EMS 急救患者的影音与心电圖（ECG）影像元数据乃至文件，含案件 UUID、设备 UUID、影像类型与时间戳，属健康/医疗个人资讯，存在个资法合规与隐私风险。socket.io 匿名握手可订阅实时事件，进一步暴露实时数据流。CORS:* 允许任意站点 JS 跨域读取上述 API 与 socket。

## Recommendation

1) 为 4001 全部 REST 集合（videoData、imageData 等）与 socket.io 通道套用与 4000/4004 相同的 JWT 认证；2) 将 Access-Control-Allow-Origin 收紧为白名单（epcr.tpf.gov.tw 等）；3) 评估历史暴露范围并对 recordUuid/CaseID/设备 UUID 脱敏或加访问控制。
