# Cookie安全配置不当

- ID: `12feac17-58da-43c5-a45d-818841789b3c`
- Severity: **medium**
- Status: open
- Type: Cookie Security Misconfiguration
- Target: `https://www.letsmakeaplan.org`
- Conversation: `c97e5501-e87e-41a7-8a52-050bc6f5acf3`
- Created: 2026-09-07 03:43:48.260414392+08:00

## Description

网站设置的Cookie缺少HttpOnly和SameSite属性，可能导致XSS和CSRF攻击。虽然网站使用了ASP.NET Session ID进行会话管理，但Cookie配置不安全。

## Reproduction

1. 访问 https://www.letsmakeaplan.org\n2. 检查响应头中的Set-Cookie字段\n3. 观察Cookie是否缺少HttpOnly和SameSite属性

## Evidence

响应头显示Cookie: ASP.NET_SessionId=xxx; path=/; secure; HttpOnly; SameSite=None，但其他Cookie未设置SameSite属性，且部分Cookie未设置HttpOnly属性。

## Impact

攻击者可能利用此漏洞进行会话劫持、XSS攻击或CSRF攻击，从而获得未授权访问权限。

## Recommendation

1. 为所有Cookie添加HttpOnly属性以防止XSS攻击\n2. 添加SameSite属性以防止CSRF攻击\n3. 确保所有敏感Cookie都标记为Secure
