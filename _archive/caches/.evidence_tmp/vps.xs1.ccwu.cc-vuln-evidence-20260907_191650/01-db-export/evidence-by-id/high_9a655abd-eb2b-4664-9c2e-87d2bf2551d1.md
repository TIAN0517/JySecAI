## Description

Port 4001 runs the EPCR "VitalSignVideoServer" (Node/Express). GET /videoData returns a 200 JSON array of emergency-video records with NO authentication (no token/cookie required). Each record contains patient emergency video metadata: id, recordUuid (dispatch UUID), fileName (e.g. [iPhone][tw.com.viewlead.emtapp...][uuid][timestamp].mp4), fileId, mimeType, generatedAt, and VideoType (現場影像 / 手機上傳 = on-scene / phone-upload). The Content-Range header confirms 101,618 total records. This is an unauthenticated bulk enumeration endpoint for a patient emergency-video record index, plus socket.io on the same host exposes access-control-allow-origin: * (wildcard CORS).

## Reproduction

1. From an unauthenticated browser or curl: `curl -sk https://epcr.tpf.gov.tw:4001/videoData`
2. Observe HTTP 200 with `Content-Range: items 0-99/101618` and a JSON array of video records containing recordUuid, fileName, fileId, mimeType, and VideoType.
3. Page through with the app's pagination (e.g. ?page= or the Content-Range/Range mechanism) to enumerate up to 101,618 records with no token.

## Impact

An unauthenticated attacker can enumerate the entire index of 101,618 emergency medical video records — a patient emergency-video metadata store — including dispatch record UUIDs, originating-device app identifiers, and on-scene/phone-upload video categories and timestamps. This enables mass enumeration and targeted access attempts against the associated /videoData/getFile/ and live RTMP (rtmp://mer2voip.tpf.gov.tw/rtmp/live) endpoints, exposing emergency-medical / patient data without any credential. Severity is elevated from an information disclosure to a significant medical-data exposure surface; combined with the wildcard CORS on socket.io and the /config architecture disclosure it indicates weak access controls across the EPCR cluster.

## Recommendation

Require authentication and authorization on /videoData (and all record/file endpoints) on port 4001; add rate limiting; do not expose the full record index or high-cardinality medical metadata unauthenticated; restrict the socket.io CORS origin to the legitimate application host instead of "*".
