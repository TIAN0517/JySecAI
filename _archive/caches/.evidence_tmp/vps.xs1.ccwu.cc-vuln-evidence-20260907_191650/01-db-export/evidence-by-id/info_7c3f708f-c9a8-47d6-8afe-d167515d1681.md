# 4000 主应用 /config 未授权泄露完整内部服务器拓扑（信息泄露）

- ID: `7c3f708f-c9a8-47d6-8afe-d167515d1681`
- Severity: **info**
- Status: open
- Type: 信息泄露
- Target: `http://epcr.tpf.gov.tw:4000/config`
- Conversation: `0e6944a5-643d-4cd9-9a2a-7b1676a25139`
- Created: 2026-09-06 15:27:46.424356169+08:00

## Description

4000 主应用（https://epcr.tpf.gov.tw:4000）的 /config 端点在未认证状态下即可访问，返回完整的内部服务器拓扑 JSON，泄露：各后端服务地址与端口（authServer:4004、hospitalServer、doctorServer、vitalSignVideoServer:4001、merBridge:4006、monitorServer:4005、statUrl:4007、mciServer:4008、printServer:9000）、视频流路径（rtmp://mer2voip.tpf.gov.tw/rtmp/live 及 https 历史视频/图片路径）、ntpcCloud 地址、captcha 配置与 MAX_IDLE_DURATION 等。该配置是前端运行时加载的公共端点，未做认证/来源限制，便于攻击者预先掌握系统架构与内网服务分布，降低后续定向攻击成本。

## Reproduction

1. curl -sS -k "http://epcr.tpf.gov.tw:4000/config"（无需任何 token/cookie）
2. 观察：HTTP 200，返回 JSON，含各后端服务端口（4001-4008、9000）、RTMP 视频流（rtmp://mer2voip.tpf.gov.tw/rtmp/live）、HTTPS 实时视频（https://mer2voip.tpf.gov.tw:30080/...）、ntpcCloud、captcha 配置等。

## Impact

未授权即可获知完整的后端服务清单、端口、RTMP/HTTPS 视频流地址与云服务地址，为攻击者提供系统架构蓝图：可据此定向扫描内网服务（如 4001 未授权数据、4006 MER bridge、mer2voip RTMP）、识别视频分发链路（mer2voip.tpf.gov.tw:30080）并尝试直连，显著缩小攻击面探索时间。

## Recommendation

1) 对 /config 增加认证或来源限制（仅允许前端 SPA 同源请求），或拆分为"前端公开配置"与"内部拓扑"两部分，仅公开必要字段；2) 移除或弱化对攻击者有价值的内部服务地址/端口/RTMP 流路径；3) 评估该配置是否可改为登录后按需获取。
