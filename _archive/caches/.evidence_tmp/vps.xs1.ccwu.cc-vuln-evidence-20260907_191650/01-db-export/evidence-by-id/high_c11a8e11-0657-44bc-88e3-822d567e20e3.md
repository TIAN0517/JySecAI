# 4001 VitalSignVideoServer /videoData 未授权读取急救影音记录（含设备/案件 UUID）

- Status: open
- Type: 未授权访问/敏感资料外泄
- Target: `https://epcr.tpf.gov.tw:4001/videoData`
- Conversation: `0e6944a5-643d-4cd9-9a2a-7b1676a25139`
- Created: 2026-09-06 14:45:04.563767797+08:00

## Description

4001 VitalSignVideoServer（https://epcr.tpf.gov.tw:4001）的 REST 资源 /videoData 完全未启用认证：GET /videoData 可分页列出全部急救影音记录（每页100条，含 recordUuid/fileName/fileId/mimeType/VideoType），GET /videoData/{id} 可按主键读取单条，且返回的 fileName 暴露 iPhone 设备 UUID（如 tw.com.viewlead.emtapp9C372D5A-7431-471E-8135-A1163FC6A7BE）与急救案件 UUID（如 180810145678）、时间戳。recordUuid 形似急救派遣案件编号，属于 EMS/患者相关影音资料，属个人/健康资讯范畴。该服务同时开启 socket.io 且 Access-Control-Allow-Origin: *。

## Reproduction

1. curl -sS -k "https://epcr.tpf.gov.tw:4001/videoData?limit=2"（无需任何 token/cookie）
2. 观察：HTTP 200，返回 JSON 数组（每页100条），含 recordUuid、fileName（含 iPhone 设备 UUID 与案件 UUID）、mimeType、VideoType。
3. curl -sS -k "https://epcr.tpf.gov.tw:4001/videoData/107" → HTTP 200 单条记录。
4. 对比需认证服务：curl -sS -k "https://epcr.tpf.gov.tw:4000/caseList" → 401 "No authorization token was found"。

## Impact

未授权访问者可枚举并读取全部急救（EMS）影音记录元数据，含案件 UUID、上传设备 UUID、时间戳与影片类型（手机/头戴式相机上传）。可据 recordUuid 关联急救案件，进一步尝试 getFile 下载实际影音内容，涉及患者/紧急医疗个人资讯外泄（个资法/健康资料风险）。CORS:* 允许任意站点 JS 跨域读取该 API。

## Recommendation

1) 为 4001 服务套用与 4000/4004 相同的 JWT 认证中间件，禁止匿名读取 /videoData；2) 将 Access-Control-Allow-Origin 从 * 收紧为白名单域（epcr.tpf.gov.tw 等）；3) 评估历史暴露的 recordUuid/设备 UUID 范围，必要时对敏感字段脱敏。
