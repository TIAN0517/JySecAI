## Impact

high - 1) 完整微服务拓扑泄露给攻击者，便于针对性 SSRF/横向攻击；2) 内部 IP 172.28.4.12:8080 暴露（内部 Socket.IO 服务）→ 直接横向；3) RTMP/视频流地址暴露可被滥用为僵尸流；4) Google Maps API Key 硬编码可被滥用为配额消耗；5) MAX_IDLE_DURATION 暴露会话超时策略。

## Recommendation

1) /config 与 /js/publicConfig.js 增加认证或仅返回白名单字段；2) 内部 IP/内部端口不下发到前端（拆分 public/private config）；3) Google Maps API Key 改用 HTTP Referer 限制 + 域名白名单；4) /js/ 目录禁止列出公共配置（移至 authenticated 端点）；5) maxIdle 等内部参数不下发。
