- ID: `79ec6fd8-e874-4394-ba72-58d690e7f0df`

- Status: open
- Type: 信息泄露 + 鉴权绕过 + 路径规范化绕过
- Target: `http://35.234.50.28:8000 (EPCRServer v1.5.24948) 与 http://35.234.50.28:3001 (statUrl)`
- Conversation: `3bc242d9-d7a8-4f06-a1fd-e41c42dea754`
- Created: 2026-08-30 06:18:09.457954381+08:00

## Description

8000 EPCRServer 静态资源未授权完整披露：express-jwt unless 漏匹配白名单路径规范化绕过。攻击者无需认证即可访问 /js/&lt;file&gt; 路径下所有 JS 文件, 泄露完整鉴权源码、RBAC权限矩阵、敏感配置信息。多个绕过技术被确认：URL编码 /js%2F&lt;file&gt;、URL编码整个 /js (%6A%73)、路径穿越 /js/../js/&lt;file&gt;、dot segment /js/./&lt;file&gt;、跨目录 dot segment /images/../js/&lt;file&gt;。审计追踪绕过(WAF/日志看到的URL与实际响应路径不一致)。

## Reproduction

1. 构造 URL: http://35.234.50.28:8000/js%2FauthInterceptorConfig.config.js (URL 编码 /)
2. 发送 GET 请求到 8000 端口
3. 验证响应: 200 OK, 响应体为完整 authInterceptorConfig.config.js 源码 (2650B)
4. 同样方式访问: /%6A%73/authInterceptorConfig.config.js (URL 编码整个 /js)
5. 同样方式访问: /js/../js/authInterceptorConfig.config.js (路径穿越)
6. 同样方式访问: /js/./authInterceptorConfig.config.js (dot segment)
7. 同样方式访问: /images/../js/authInterceptorConfig.config.js (跨目录 dot segment)
8. 所有路径均返回 200 OK + 完整源码

## Impact

1. 审计追踪绕过：WAF/日志看到的URL与实际响应路径不一致, 绕过基于URL特征的WAF规则
2. 文件枚举：攻击者可通过字典攻击发现未知名 JS/JSON/HTML 文件
3. 权限矩阵/RBAC/认证源码泄露：完整鉴权代码 + 13角色 × 60+权限矩阵
4. 串联利用：配合 /images/../js/ 绕过可访问 /js/ 任意文件
5. 后期利用：用此绕过访问未知的 JS 文件 (private keys, AWS credentials, internal API)
6. 表达式注入: authInterceptorConfig.config.js 的 $injector.invoke 可注入任意依赖服务 (CWE-285 High)
7. 前端鉴权绕过: AuthService.js checkPerm + jwtHelper.decodeToken 无签名校验, 伪造 JWT payload.permissions 即可绕过 UI 权限显示 (CWE-863 High)

## Recommendation

1. 不要使用 unless 漏匹配白名单, 应将静态资源路由放在 express-jwt 之前注册
2. 路径规范化：在 express-jwt 检查前调用 path.normalize() 或强制使用 /^\\/js\\// 正则
3. nginx 反代：在 nginx 层 merge_slashes off + 严格路径规范化
4. WAF规则：添加基于 /js%2F, /%6A%73, /js/../, /js/./ 等混淆模式的检测
5. 服务端鉴权：所有鉴权必须在服务端执行, 不依赖前端 checkPerm
6. 签名验证：jwtHelper.decodeToken 必须先 verify() 签名才能解析 payload
