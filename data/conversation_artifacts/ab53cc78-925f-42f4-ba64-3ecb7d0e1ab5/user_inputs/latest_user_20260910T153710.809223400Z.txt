## 安全影响

1. **任意字典污染**：第三方页面可批量写入字典条目，影响字典可用性与审计完整性
2. **Stored XSS 触发链**：写入 name 字段后，/MciTypes GET 集合层字面输出（已实测无 HTML 转义），前端 v-html 渲染时直接执行 JS → 窃取 session/JWT/CSRF token
3. **审计日志污染**：与 MethodOverride:PUT/DELETE 组合可伪造审计轨迹，干扰事件调查
5. **CORS 反射形同虚设**：vary: Origin 仅作 CORS 头反射，未对非主域 Origin 拒绝 form POST，未实施 SameSite cookie 防护

## 修复建议

1. 立即为 /MciTypes 添加 JWT 鉴权中间件（与 LoopBack 默认 /api/* 路由一致）
2. 实施 CORS Origin 严格白名单：拒绝非主域 Origin 的写操作
3. 引入 CSRF Token 验证（双 cookie、SameSite=Strict 等）
4. 对 name 字段实施 HTML 转义 + 长度限制 + 字符过滤（Stored XSS 防御）
5. 限制字典容量 + 写入频率，避免字典污染 DoS

## 复测验证方法

修复后复测：1) POST /MciTypes 任意 Origin 应返回 401（JWT 缺失）；2) form POST 表单钓鱼应被 CSRF Token 拦截；3) /MciTypes 任意 Origin 应返回 403 而非 200
