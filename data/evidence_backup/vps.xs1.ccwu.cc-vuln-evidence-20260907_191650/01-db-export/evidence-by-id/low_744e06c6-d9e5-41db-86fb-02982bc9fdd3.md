# 4006 MerBridge IP 白名單無法繞過

- ID: `744e06c6-d9e5-41db-86fb-02982bc9fdd3`
- Severity: **low**
- Status: open
- Type: 訪問控制 / IP 白名單
- Target: `https://epcr.tpf.gov.tw:4006/`
- Conversation: `d616190f-0d59-4d31-882b-33ba2ea72121`
- Created: 2026-08-29 19:28:27.520554338+08:00

## Description

4006 MerBridge 所有端點（/config、/version、/events、/socket.io/、/api/dispatch 等 20+ 端點）均返回 403 "Access denined"（拼寫錯誤），嘗試 13 種 fake IP 頭（X-Forwarded-For、X-Real-IP、X-Originating-IP、X-Remote-IP、X-Remote-Addr、X-Client-IP、X-Host、Forwarded）使用 172.28.4.12/127.0.0.1/118.163.107.92 三種目標 IP + Host 頭注入均無法繞過，IP 白名單在 TCP 層/應用層早期

## Preconditions

無 - 該端點公開但完全受 IP 白名單保護

## Reproduction

1. 從公網向 https://epcr.tpf.gov.tw:4006/config 發送 GET 請求：
   ```
   curl -v https://epcr.tpf.gov.tw:4006/config
   ```
2. 觀察響應：應返回 HTTP 403 Forbidden，body 為 "Access denined"
3. 添加 fake IP 頭重試：
   ```
   curl -v https://epcr.tpf.gov.tw:4006/config -H 'X-Forwarded-For: 172.28.4.12'
   ```
4. 觀察響應：仍然 HTTP 403 Forbidden "Access denined"
5. 嘗試其他 IP 頭（X-Real-IP、X-Originating-IP 等）和不同 IP 值（127.0.0.1、118.163.107.92），均無法繞過
6. 嘗試 Host 頭注入：
   ```
   curl -v https://epcr.tpf.gov.tw:4006/config -H 'Host: 172.28.4.12'
   ```
7. 觀察響應：仍然 403
8. 結論：4006 MerBridge 的 IP 白名單在 TCP 層/應用層早期生效，fake IP 頭無法繞過

  Vary: Origin

## Impact

由於 4006 MerBridge 處於 TCP/IP 層早期的 IP 白名單保護，無法從外部攻擊該服務。需要從內網（172.28.4.12）或通過其他方式訪問。此發現屬於正向安全措施（IP 白名單生效），但拼寫錯誤「Access denined」暴露 Express 中間件應用位置且錯誤拼寫影響維護性。

## Recommendation

1. 在應用層而非 TCP 層實施 IP 白名單（便於日誌記錄）；2. 修復 OPTIONS 響應中的方法暴露（移除不必要的 PATCH/PUT 等）；3. 修正「denined」拼寫錯誤（應為「denied」）；4. 將內部 MerBridge 服務置於不可直接從公網訪問的網段；5. 添加適當的 WAF 規則和速率限制；6. 在 403 響應中不暴露錯誤拼寫以避免中間件位置洩漏。
