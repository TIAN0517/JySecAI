- ID: `2717903a-e433-4116-b596-e88f0e4d9092`
- Severity: **high**
- Status: open
- Type: Broken Access Control
- Target: `https://epcr.tpf.gov.tw:4001/events`
- Conversation: `667feba8-aeb6-43db-baa4-1e16ab996122`

## Description

GET /events 端点无需任何认证即可访问，返回 567,201 条 PCDT（压力负荷试验）事件数据。每条记录包含 CaseID、recordUuid、Caption、TypeOfEventTxt、TypeOfEventNum、Elapsed、Timestamp、Systolic、Diastolic、Mean、BPUnit、Annotation 等完整医疗数据。支持 content-range 分页（items 0-99/567201）。

## Reproduction

1. 发送 GET 请求：`curl -sk "https://epcr.tpf.gov.tw:4001/events?limit=5"`
2. 观察响应：HTTP 200 OK
3. 检查 header：`content-range: items 0-99/567201`
4. 检查 body：JSON 数组，包含 CaseID、recordUuid、血压数据等
5. 遍历分页：`curl -sk "https://epcr.tpf.gov.tw:4001/events?range=100-199"` 获取下一页

## Impact

**中等-高** - 泄露大量医疗 PCDT 压力负荷试验数据，包含：
1. **患者标识**：CaseID（如 180717152801fed7）、recordUuid
2. **医疗数据**：血压（Systolic/Diastolic/Mean）、事件类型（PCDT 开始/结束、标记、学习心律等）
3. **时间信息**：Timestamp、Elapsed（试验持续时间）
4. **元数据**：createdAt、updatedAt
5. **数据量**：567,201 条记录，时间跨度从 2018 年至今

攻击者可通过分页遍历全部数据，构建患者压力负荷试验历史记录，用于身份关联、医疗记录泄露或进一步攻击。

## Recommendation

1. **添加认证**：要求 JWT Bearer Token 或 API Key
2. **添加授权**：验证用户是否有权访问特定 CaseID 的数据
3. **添加速率限制**：防止遍历大量数据
4. **添加分页限制**：默认限制每页返回数量（如 100 条）
5. **添加审计日志**：记录未授权访问尝试
