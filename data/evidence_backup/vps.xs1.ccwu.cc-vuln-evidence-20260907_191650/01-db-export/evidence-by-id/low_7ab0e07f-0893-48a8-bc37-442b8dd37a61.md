# 4006 端口 (MerBridge) 所有端点返回 403 Forbidden，服务暴露但访问受限

- ID: `7ab0e07f-0893-48a8-bc37-442b8dd37a61`
- Severity: **low**
- Status: open
- Type: 信息泄露
- Target: `https://epcr.tpf.gov.tw:4006 (MerBridge)`
- Conversation: `667feba8-aeb6-43db-baa4-1e16ab996122`
- Created: 2026-08-29 07:41:16.188483847+08:00

## Description

4006 端口 (MerBridge) 的所有端点均返回 403 Forbidden，Access denied，表明服务存在但需要特定认证或 IP 白名单。

## Reproduction

1. 使用 curl 发送 GET 请求到 4006 端口的任意端点：
   ```bash
   curl -sk https://epcr.tpf.gov.tw:4006/
   ```
2. 观察响应：返回 403 状态码，Body 为 "Access denied"
3. 测试其他端点（/config, /api, /health 等），确认均返回 403
4. 检查响应头，确认 Content-Type 为 text/html

## Evidence

```bash
$ curl -sk https://epcr.tpf.gov.tw:4006/
HTTP/1.1 403 Forbidden
Content-Type: text/html; charset=utf-8
Content-Length: 14

Access denied

$ curl -sk https://epcr.tpf.gov.tw:4006/config
HTTP/1.1 403 Forbidden
Access denied

$ curl -sk https://epcr.tpf.gov.tw:4006/api
HTTP/1.1 403 Forbidden
Access denied

$ curl -sk https://epcr.tpf.gov.tw:4006/health
HTTP/1.1 403 Forbidden
Access denied
```

## Impact

1. **服务暴露**：虽然返回 403，但表明服务存在且正在运行
2. **指纹识别**：固定的 "Access denied" 响应体帮助攻击者识别服务类型
3. **潜在绕过**：如果 403 是基于 IP 白名单或认证头，可能存在绕过机会
4. **信息泄露**：403 错误本身泄露了访问控制策略的存在

## Recommendation

1. **统一错误响应**：对未授权访问返回 401 Unauthorized 而非 403 Forbidden
2. **隐藏服务**：如果服务仅内部使用，考虑绑定到内网 IP 或使用防火墙规则
3. **添加认证**：为所有端点添加认证机制
4. **最小化响应**：减少错误响应的信息量，避免泄露实现细节
