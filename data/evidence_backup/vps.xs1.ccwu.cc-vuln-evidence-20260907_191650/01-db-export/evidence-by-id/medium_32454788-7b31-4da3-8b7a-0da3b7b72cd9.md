# 4000 根路径 CSP 泄露完整微服务拓扑 + GCP IP + unsafe-inline

- ID: `32454788-7b31-4da3-8b7a-0da3b7b72cd9`
- Severity: **medium**
- Status: open
- Type: CSP 配置缺陷 / 敏感信息泄露
- Target: `https://epcr.tpf.gov.tw:4000/`
- Conversation: `9f0a20d8-98b0-4f97-8e49-573ac9d822dc`
- Created: 2026-09-01 06:17:56.147226986+08:00

## Description

4000 EPCR 前端根路径响应头 Content-Security-Policy 泄露了全部 10 个微服务地址（4000-4008/9000）、GCP IP 35.234.50.28、localhost:8100/18081，且 script-src 包含 'unsafe-inline' 与 *，几乎无 CSP 保护。攻击者可据此一次性映射整个系统架构，并利用 unsafe-inline 注入内联脚本，削弱 XSS 防护。

## Preconditions

公网可达 https://epcr.tpf.gov.tw:4000

## Reproduction

1. curl -sk -D - 'https://epcr.tpf.gov.tw:4000/'
2. 查看 Content-Security-Policy 头
3. 确认包含 4001-4008/9000 端口、35.234.50.28、localhost:8100/18081
4. 确认 script-src 包含 'unsafe-inline' 与 *

## Evidence

curl -sk -D - 'https://epcr.tpf.gov.tw:4000/' 返回 HTTP 200，Content-Security-Policy: default-src 'self' * blob: http://epcr.tpf.gov.tw:4000 https://epcr.tpf.gov.tw:4001 https://epcr.tpf.gov.tw:4002 https://epcr.tpf.gov.tw:4003 https://epcr.tpf.gov.tw:4004 http://epcr.tpf.gov.tw:4005 https://epcr.tpf.gov.tw:4006 https://epcr.tpf.gov.tw:4007 http://epcr.tpf.gov.tw:9000 http://35.234.50.28 http://localhost:8100 http://localhost:18081;script-src 'self' 'unsafe-inline' *.gstatic.com *.googleapis.com *.ggpht maps.google.com * blob:

## Impact

CSP 泄露完整微服务拓扑与 GCP IP，可针对性横向渗透；script-src 含 unsafe-inline + *，内联脚本与任意域脚本均可执行，削弱 XSS 防护；img-src 也含全部微服务地址，可被利用做跨域图片加载（信息泄露/指纹识别）。

## Recommendation

收紧 CSP 到最小必要域，移除 unsafe-inline 与 *；对 CSP 中的内部地址做脱敏（如仅保留域名不保留端口）；对 GCP IP 做代理或隐藏，避免直接暴露。
