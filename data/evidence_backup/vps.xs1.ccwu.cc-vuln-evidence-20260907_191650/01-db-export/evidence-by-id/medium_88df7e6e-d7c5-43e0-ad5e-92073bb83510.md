# EPCR vitalSignVideoServer /events 信息泄露 — Content-Range 暴露数据库规模 + 弱 ETag 暴露框架

- ID: `88df7e6e-d7c5-43e0-ad5e-92073bb83510`
- Severity: **medium**
- Status: open
- Type: 信息泄露（Information Disclosure + Improper Handling of Inadequate Information）
- Target: `https://epcr.tpf.gov.tw:4001/events`
- Conversation: `d03a3dde-0b73-440d-8d22-57bb72586e05`
- Created: 2026-08-30 17:44:37.323093194+08:00

## Description

目标 `https://epcr.tpf.gov.tw:4001/events` 端点直接在 HTTP 响应头暴露 `Content-Range: items 0-99/567239`。任何无鉴权客户端通过该头部即可实时获取数据库总记录数；并且通过 DELETE/POST 前后两次读取即可侧信道观测到数据库已被改写（Content-Range 实测：写入 V5 PoC 后 /567240，DELETE 后回落 /567239）。同时弱 ETag `W/"xxx-..."` 直接暴露 Express + Sequelize 框架指纹；Vary: Origin 头暗示框架曾考虑 CORS 但未实施；strict-transport-security/max-age 启用说明团队对安全有部分意识但执行不一致。

## Reproduction

1. 任意 HTTP 客户端
2. 执行 `curl -sI https://epcr.tpf.gov.tw:4001/events`
3. 观察响应头中 `content-range: items 0-99/567239` 与 `etag: W/"..."` 弱 ETag
4. 写入测试事件 `curl -X POST ... /events`，GET 列表观察 content-range /567240
5. 删除测试事件 `curl -X DELETE ... /events/<id>`，GET 列表观察 content-range /567239
6. 通过对比两次计数差可验证删除落地

## Impact

1. **数据库规模外泄**：任何未鉴权客户端可获取 567,239 条记录的总数（医疗事件），帮助攻击者评估数据价值与抓取进度
2. **写删落地观察**：POST/DELETE 操作前后 Content-Range 实时变化，证明数据库被实际改写，为攻击提供"是否落地"的实时 oracle（可用于自动化攻击循环）
3. **框架指纹泄露**：弱 ETag `W/"xxxx-..."` 暴露 Express + 弱哈希算法（base64 长度），攻击者可针对性搜索 Express 已知漏洞
4. **Vary: Origin 暗示 CORS 半成品**：可能存在 CORS 误配漏洞；攻击者可在浏览器侧尝试 Origin 反射测试
5. **中间人攻击面**：HSTS 启用但 expect-ct: max-age=0 已弃用，部分客户端不强制证书透明度检查

## Recommendation

1. **移除 Content-Range**：分页仅在认证+授权后通过自定义响应头（如 `X-Total-After-Auth: 567239`）返回；NOAUTH 默认 200 + 空列表或 401
2. **强 ETag**：替换弱 ETag 为强 ETag（SHA256 内容哈希），并在 If-None-Match 命中时返 304
3. **补全安全响应头**：
   - `Content-Security-Policy: default-src 'self'; object-src 'none'; frame-ancestors 'none'; base-uri 'none'`
   - `X-XSS-Protection: 1; mode=block`
   - `Cross-Origin-Opener-Policy: same-origin`
   - `Cross-Origin-Resource-Policy: same-origin`
   - 移除 `vary: Origin`（未实施 CORS 不应暗示支持）
4. **审计日志**：所有 POST/DELETE 操作记录 IP/UA/时间/payload diff/Content-Range 变化，供司法取证
5. **去除 X-Powered-By**：移除 `X-Powered-By: Express`（如存在）
