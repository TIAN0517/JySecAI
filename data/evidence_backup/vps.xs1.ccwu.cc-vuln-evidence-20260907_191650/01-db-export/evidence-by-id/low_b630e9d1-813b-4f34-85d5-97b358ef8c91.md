## Description

nfaemsap2.nfa.gov.tw（NFA SSO 中心，与 nfaemsap3 同源的副本，未被 nfaemsap3 的 WAF 封禁）承载 /SSO/ 登录页（6716B）与 /SSO/login 端点，技术栈为 Spring Security + Thymeleaf（xmlns:sec thymeleaf-extras-springsecurity3，<title>National Fire Agency</title>）。登录表单字段为 account/password/country/verificationCode，验证码端点 /SSO/file/Verification 返回 PNG(120x40) 且会话绑定、每次刷新（非固定可重放）。安全方面：登录失败返回统一模糊错误"帳戶、密碼、縣市別有誤，或密碼不符合GCB規範，或驗證碼有誤"（不区分具体字段，不易账号枚举）；account 参数单引号未触发 SQL 错误（无明显注入）；验证码空值/固定值均判"有误"（无绕过）。但应用启用了 JSESSIONID URL rewriting——所有资源 URL 均携带 ;jsessionid=xxxx 后缀（如 /SSO/bootstrap/css/bootstrap.min.css;jsessionid=4C518E72C8BE1B3DC1A79B2F54BEFC6C），且 JSESSIONID cookie 的 Path 为 /SSO。

## Reproduction

1) 访问 https://nfaemsap2.nfa.gov.tw/SSO/；2) 观察页面所有资源 URL 均带 ;jsessionid= 后缀（如 bootstrap.min.css;jsessionid=...）；3) POST /SSO/login 提交任意凭证，返回 200 与统一错误"帳戶、密碼、縣市別有誤..."；4) 对比 nfaemsap3 同路径当前 SSL reset（WAF 封禁），说明 nfaemsap2 为可达副本。

## Impact

JSESSIONID URL rewriting 使会话标识出现在所有资源 URL 中，可能通过 Referer 头、浏览器历史、代理/CDN 日志、共享链接等渠道泄露，增加会话劫持/固定攻击面。此外 SSO 作为 NFA 全部 EMS 应用（nfaemsap3/dacpr/gis 等）的统一入口，其可达副本（nfaemsap2）扩大了暴露面。登录错误信息统一、验证码会话绑定、无明显注入——认证逻辑本身较稳健，但 JSESSIONID 暴露与会话管理可改进。

## Recommendation

1) 关闭 JSESSIONID URL rewriting（仅依赖 HttpOnly+Secure+SameSite Cookie 传递会话），避免会话 ID 出现在 URL；2) 为 JSESSIONID cookie 增加 Secure 与 SameSite=Strict/Lax 属性（当前未见 Secure/SameSite）；3) 统一 SSO 各副本（nfaemsap2/3）的 WAF/限流策略，避免副本绕过主站封禁；4) 对 /SSO/login 增加登录失败速率限制与锁定策略。
