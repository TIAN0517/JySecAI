## Description

无。token 可从任意未认证访客下载的公开 JS 包中提取。

## Impact

1) 冒用 bot 身份：攻击者可作为"官方监控/告警机器人"向运营群组（chat_id -5170878759）及任何与该 bot 对话的用户发送任意消息 → 针对运营/客服团队的高可信度钓鱼与社会工程（骗取后台凭据、诱导点击）。2) 破坏监控：deleteWebhook/setWebhook 可劫持或中断其错误上报通道。3) 若客户端 sendTgMessage 实际将错误/请求上下文（可能含敏感数据）推送到该群，任何拿到 token 者可读取该群消息（视 webhook 配置），扩大为敏感数据外泄。属硬编码凭证泄露，违反 CWE-798。

## Recommendation

1) 立即在 BotFather 撤销/重置该 bot token（/revoke）。2) 严禁将任何密钥/token 下发到前端；错误上报应经由服务端代理转发，token 仅存于服务端。3) 排查该 bot 的历史消息与群成员，评估是否已有敏感数据泄露或被冒用。4) 建立前端构建产物的密钥扫描（如 trufflehog/gitleaks）纳入 CI。5) 修复后复测：确认包内不再含 token，旧 token 已失效。
