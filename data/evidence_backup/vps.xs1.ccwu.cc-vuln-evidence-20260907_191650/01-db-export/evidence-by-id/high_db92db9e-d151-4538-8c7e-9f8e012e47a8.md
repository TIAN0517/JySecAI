- Status: confirmed
- Type: Broken Access Control / 未授权访问
- Target: `https://epcr.tpf.gov.tw:4001/events (GET)`
- Conversation: `667feba8-aeb6-43db-baa4-1e16ab996122`

## Description

vitalSignVideoServer (端口 4001) 的 /events 端点无需认证即可访问，返回完整的 PCDT (运动负荷试验) 事件数据，包含患者 CaseID、记录 UUID、时间戳、血压等敏感医疗信息。

## Reproduction

1. 打开终端
2. 执行命令: `curl -sk "https://epcr.tpf.gov.tw:4001/events"`
3. 观察响应状态码: 200 OK
4. 解析 JSON 响应，查看事件数据数组
5. 验证数据包含 CaseID、recordUuid、Timestamp、Systolic、Diastolic 等字段
6. (可选) 使用 jq 过滤: `curl -sk "https://epcr.tpf.gov.tw:4001/events" | jq '[.[] | select(.TypeOfEventTxt == "BP")]'`

## Impact

1. **患者隐私泄露**: 567,201 条 PCDT 运动负荷试验事件记录暴露
2. **医疗数据敏感**: 包含血压 (收缩压/舒张压/平均压)、时间戳、事件类型
3. **数据量**: 59 个唯一 CaseID，可能对应 59 位患者
4. **时间跨度**: 2018-07-17 至 2018-08-17 (约 1 个月)
5. **可分页访问**: 支持 content-range 分页，可遍历全部数据
6. **业务影响**: PCDT 是诊断心脏疾病的重要检查，数据泄露可能影响患者隐私和医疗记录完整性

## Recommendation

1. **添加认证机制**: 在 /events 端点前添加 JWT 认证中间件，要求有效的 Bearer Token
2. **速率限制**: 实施速率限制防止数据遍历 (如每分钟 60 次请求)
3. **分页限制**: 限制单次请求返回的最大记录数 (如最多 100 条)
4. **数据脱敏**: 考虑对敏感字段 (如血压值) 进行脱敏处理
5. **访问日志**: 记录所有对 /events 的访问，便于审计
6. **API 网关**: 通过 API 网关统一管理认证和授权

**验证方法:**
修复后，无 Token 访问应返回 401:
```bash
curl -sk "https://epcr.tpf.gov.tw:4001/events"
# 期望: 401 Unauthorized
```

有 Token 访问应返回 200:
```bash
curl -sk "https://epcr.tpf.gov.tw:4001/events" -H "Authorization: Bearer <valid_token>"
# 期望: 200 OK
```
