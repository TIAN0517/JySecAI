# EPCR /config 端点未授权泄露内部服务拓扑

- ID: `b85619e5-8406-43f3-8b51-8e9fd62fe603`
- Severity: **medium**
- Status: confirmed
- Type: 信息泄露
- Target: `https://epcr.tpf.gov.tw:4000/config, https://epcr.tpf.gov.tw:4002/config, https://epcr.tpf.gov.tw:4003/config`
- Conversation: `667feba8-aeb6-43db-baa4-1e16ab996122`
- Created: 2026-08-29 05:58:13.732326297+08:00

## Description

EPCR 前端 (4000) /config 端点无需认证即可访问，返回完整的微服务拓扑 JSON，泄露所有后端服务 URL（4001-4008、9000）、RTMP 直播流地址、内部云门户地址等敏感架构信息。

## Reproduction

1. 访问 https://epcr.tpf.gov.tw:4000/config
2. 无需认证，直接返回 200 OK + JSON
3. 解析 JSON 获取所有内部服务 URL
4. 同样测试 https://epcr.tpf.gov.tw:4002/config 和 https://epcr.tpf.gov.tw:4003/config

## Impact

1. 架构泄露：完整微服务拓扑暴露，攻击者可精准定位关键服务
2. 内部服务发现：4005/9000 使用 HTTP 明文，可能被中间人攻击
3. RTMP 直播流暴露：可直接构造视频 URL 访问实时医疗监控画面
4. 攻击面扩大：发现 mer2.tpf.gov.tw:7000、cloud2.ntpc.gov.tw 等额外攻击目标

## Recommendation

1. 将 /config 端点移至需要认证的路由（如 /api/config 或 /internal/config）
2. 或在响应头添加 X-Config-Source: internal 并在前端校验
3. 将 4005/9000 迁移到 HTTPS
4. 对 RTMP 流添加访问令牌验证
5. 考虑使用环境变量或配置文件分离，避免在生产环境暴露完整拓扑
