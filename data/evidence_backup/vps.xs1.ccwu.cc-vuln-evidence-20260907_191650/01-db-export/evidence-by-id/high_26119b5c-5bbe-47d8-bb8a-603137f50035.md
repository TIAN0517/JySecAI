# EPCR :4001 /imageData/{id} 与 /videoData/{id} 未授权 IDOR 单条精确读取

- ID: `26119b5c-5bbe-47d8-bb8a-603137f50035`
- Severity: **high**
- Status: open
- Type: IDOR/未授权精确读取
- Target: `https://epcr.tpf.gov.tw:4001/imageData/{id} 与 /videoData/{id}`
- Conversation: `0e6944a5-643d-4cd9-9a2a-7b1676a25139`
- Created: 2026-09-06 18:34:05.7021911+08:00

## Description

EPCR 集群 4001 端口（裸 Node.js/Express 媒体服务，无鉴权中间件）的 /imageData/:id 与 /videoData/:id 端点支持按数字 id 精确查询单条记录，且无需任何认证 token。与 /imageData、/videoData 的批量列表端点不同，此单条端点允许通过遍历 id（1,2,3...）逐条精确读取所有急救影像/影音记录。每条记录含 recordUuid（案件/设备标识）、fileName（含设备 UUID 与时间戳，如 [iPhone][tw.com.viewlead.emtapp<UUID>][<时间>].MP4）、fileId、mimeType、generatedAt（精确到毫秒）、ImageType/VideoType（心電圖/波型/手機上傳）等字段。攻击者可在完全未登录状态下遍历 id 枚举并逐条读取全部急救影音与心电图数据，实现精确的 IDOR 式越权读取。

## Reproduction

1) 浏览器/任意 HTTP 客户端访问 https://epcr.tpf.gov.tw:4001/imageData/1000（无需登录/Cookie/Token）；2) 观察返回 200 与单条 JSON 记录（含 recordUuid、fileName、mimeType、generatedAt、ImageType）；3) 改 id 为 2、100、10000 均 200，id=1 为 404；4) 同法测试 /videoData/:id。

命令: curl -sSk -A "Mozilla/5.0" https://epcr.tpf.gov.tw:4001/imageData/1000

## Impact

未授权攻击者可通过遍历数字 id 逐条精确读取全部急救影像与影音记录（心电图、波型、手机上传视频），每条含设备 UUID、精确时间戳、案件 recordUuid。结合批量列表（10 万条）与单条 IDOR 读取，可实现对 EPCR 急救影像数据库的完整未授权枚举与定向查询，进一步加剧患者隐私与设备信息泄露，并可用于追踪特定设备/案件的历史记录。

## Recommendation

1) 为 4001 端口的 /imageData、/videoData 及所有子路由（含 :id 单条）统一挂载认证中间件（与 4000 的 JWT 校验一致），拒绝无 token 访问；2) 单条 :id 端点增加基于请求者权限的归属校验（防止 IDOR）；3) 最小化响应字段，去除设备 UUID、fileId 等内部标识；4) 对枚举型端点加速率限制与 id 序列防护。
