# 4000 端口 /version/ 端点未授权访问 - 泄露系统版本信息

- ID: `9030665b-afbd-4016-8743-1fe6064d265f`
- Severity: **low**
- Status: open
- Type: Information Disclosure
- Target: `https://epcr.tpf.gov.tw:4000/version/`
- Conversation: `667feba8-aeb6-43db-baa4-1e16ab996122`
- Created: 2026-08-29 04:52:08.94453096+08:00

## Description

GET /version/ 端点无需任何认证即可访问，返回系统版本信息 "1.6.26080"。该信息可帮助攻击者识别特定版本的已知漏洞。

## Reproduction

1. 发送 GET 请求：`curl -sk "https://epcr.tpf.gov.tw:4000/version/"`
2. 观察响应：HTTP 200 OK
3. 检查 body：`1.6.26080`

## Evidence

```
$ curl -sk "https://epcr.tpf.gov.tw:4000/version/"
HTTP/1.1 200 OK
content-type: text/html; charset=utf-8
content-length: 9

1.6.26080
```

## Impact

**低-中** - 版本信息泄露可用于：
1. 识别特定版本的已知 CVE
2. 针对性利用该版本的漏洞
3. 判断系统是否及时更新
4. 辅助攻击者选择攻击策略

结合已发现的未授权访问漏洞（/config、/events），版本信息泄露可帮助攻击者更精准地定位攻击目标。

## Recommendation

1. **添加认证**：要求 JWT Bearer Token
2. **限制访问**：仅允许内部网络或特定 IP 访问
3. **隐藏版本**：生产环境不暴露详细版本号
4. **添加缓存**：减少频繁访问
