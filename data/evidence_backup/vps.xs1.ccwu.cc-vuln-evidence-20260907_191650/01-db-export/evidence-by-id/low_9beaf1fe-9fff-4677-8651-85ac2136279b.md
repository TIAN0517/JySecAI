# Port 4001 socket.io wildcard CORS and unauthenticated service exposure

- ID: `9beaf1fe-9fff-4677-8651-85ac2136279b`
- Severity: **low**
- Status: open
- Type: Misconfiguration / Insecure CORS
- Target: `https://epcr.tpf.gov.tw:4001/socket.io/`
- Conversation: `0e6944a5-643d-4cd9-9a2a-7b1676a25139`
- Created: 2026-09-02 23:45:36.035658106+08:00

## Description

The port 4001 VitalSignVideoServer exposes a socket.io endpoint (/socket.io/?EIO=4&transport=polling) that returns access-control-allow-origin: * (wildcard CORS) with no authentication. Combined with the unauthenticated /videoData index on the same host, any arbitrary origin can establish a cross-origin socket.io connection to the emergency-video/vitalsign server. The bare Express index ("Welcome to Express") is also served without auth, confirming port 4001 is a fully open API/service host.

## Reproduction

1. `curl -sk -D - https://epcr.tpf.gov.tw:4001/socket.io/?EIO=4\&transport=polling`
2. Observe HTTP 200 with `access-control-allow-origin: *` and no authentication required.
3. `curl -sk https://epcr.tpf.gov.tw:4001/` returns the default "Welcome to Express" page (170 bytes) unauthenticated.

## Evidence

Request:
GET /socket.io/?EIO=4&transport=polling HTTP/1.1
Host: epcr.tpf.gov.tw:4001
(no auth)
Response: HTTP/1.1 200 OK
access-control-allow-origin: *

Root: GET / -> HTTP 200, content-length 170, body "<h1>Express</h1><p>Welcome to Express</p>" (bare default Express app, no auth).

## Impact

Wildcard CORS on a real-time (socket.io) endpoint that carries emergency-video / vitalsign data allows any web page to connect cross-origin and potentially subscribe to/receive live streams or push data. On a fully unauthenticated service host this weakens the isolation of the emergency-video system and enables cross-origin interaction with the socket from attacker-controlled pages.

## Recommendation

Restrict the socket.io CORS origin to the legitimate application origin (or require authentication/origin validation); do not use wildcard CORS on real-time data endpoints; remove the default Express welcome page on production.
