## Description

GET https://epcr.tpf.gov.tw:4001/events 无需任何认证，返回 200 OK + 567,232 条真实医疗 PCDT 压力负荷试验事件记录。响应头 Content-Range: items 0-99/567201，含 CaseID、recordUuid、TimeStamp、Systolic/Diastolic/Mean（生命征象）、Annotation、TypeOfEventTxt 等敏感 PHI 字段。响应还泄露 x-powered-by: Express 与 x-xss-protection: 0（禁用浏览器XSS过滤）。
此外 Sequelize ORM 操作符注入 $ne/$gt/$exists/$regex/$type 可触发 val.replace is not a function 500 错误，泄露 ORM 内部实现细节（确认 Sequelize）。

## Preconditions

无需前置条件 - 完全无认证

## Reproduction

1. 直接 curl -k https://epcr.tpf.gov.tw:4001/events （无需任何 header/cookie/token）
2. 观察响应：HTTP 200 + Content-Range: items 0-99/567201 + JSON 数组 100 条
3. 用 Range header 翻页（实际被忽略，但可绕过 default 100 限制）
4. 用 ?CaseID[$ne]= 触发 NoSQL 注入列出所有 CaseID
5. 用 ?recordUuid[$regex]=. 触发 Sequelize 500 错误

## Impact

critical - 567,232 条未加密医疗 PCDT 事件可无认证遍历导出，包含真实病人 CaseID 与生命征象数据。违反 HIPAA/个资法/医疗法相关法规。攻击者可批量爬取整个 EPCR 医疗数据库并用于身份伪造、医疗欺诈、研究数据窃取。
NoSQL 操作符注入与 ORM 500 错误进一步暴露 ORM 实现细节为后续攻击提供情报。

## Recommendation

1) 立即对 4001 vitalSignVideoServer 的 /events 路由实施认证（JWT/SSO 检查）；2) 启用 per-hospital UUID 鉴权；3) 关闭 ORM 错误堆栈（生产环境）；4) 修复 Sequelize 操作符注入（sanitize req.query，禁止 $ 开头 key）；5) 启用 x-xss-protection: 1; mode=block；6) 审计历史访问日志查找异常数据导出。
